# 创探空间｜淘宝手机店铺概念图切片

本包按选定的方案二修订图裁切。图片内容为视觉概念：其中的商品、包装、型号、年龄标识、页面按钮和店铺数据均非真实商品资料。上线前请用在售商品实拍图与真实信息替换商品区域，并在千牛装修后台给图片按钮设置实际跳转链接。

## 750px 宽整栏切片

| 文件 | 像素尺寸 | 内容 |

## 使用建议

1. 优先在手机端装修中按顺序放置三张整栏图；如果该组件支持热区，再为首图按钮、品类入口及商品卡设置跳转。
2. 店铺顶部的搜索、关注、导航等由平台自身显示，不要把完整效果图直接上传。
3. 商品推荐区应替换成店铺真实在售的积木、科学实验器材及真实包装图，再发布。
