3-cheng-bao LDraw part backup

source-mpd/ keeps the original packed MPD copy.
mpd-files/ keeps every 0 FILE block split out with its MPD file name.
studio-library/ is arranged as an LDraw/Studio custom library: copy its parts/ and p/ folders into Studio CustomParts.
direct-parts/ contains only the top-level parts used directly by the castle model.

Common Studio path on this Windows user:
C:\Users\Administrator\AppData\Local\Stud.io\CustomParts\

After copying, restart Studio or reload custom parts.
