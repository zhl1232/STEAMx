3437pb049.dat Studio custom part export

Use direct-parts/3437pb049.dat if Studio only asks for a single DAT file.
Use studio-library/ if Studio needs a full custom LDraw library folder; copy its parts/ and p/ folders into Studio CustomParts.

Common Studio custom parts path on this Windows user:
C:\Users\Administrator\AppData\Local\Stud.io\CustomParts\

The part geometry is exported from the official LDraw 3437pe1.dat eye-pattern Duplo brick and renamed to the Studio/lesson identifier 3437pb049.dat.
