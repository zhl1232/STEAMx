# Scratch 7–10 岁家庭课程

本目录提供 6 个阶段、48 节原创 Scratch 课。每节按家庭约 30 分钟设计，允许孩子独立尝试，成人只在设备操作或阅读时提供支持。课程从角色和事件出发，逐步加入回应、游戏规则、角色协作、数据规律，最后完成可解释、可试玩的个人作品。

## 唯一内容来源与字段

- `lessons.json` 是课程正文唯一来源，按 `s01-l01` 到 `s06-l08` 排序。
- 每节包含 1-based `stageIndex`、连续 `sortOrder`、`durationMinutes`（20–45）、`goals`、`prerequisites`、`steps`、`challenge`、`reflection`、`requiredBlocks`、`projectGoal` 和 `scenarioKey`。
- 每节至少六步；第 2–4 步是可以边看边搭的操作卡：先放事件帽子，再按从上到下的顺序连接语句积木，并把 reporter 写在明确的判断或输入槽里。每张卡点名角色、参数默认值、连接/嵌套关系、预测结果，以及一个可复现的问题、单点修复和同输入复测。需要合作的课会把角色拆成独立脚本，消息接收脚本不能和发送脚本混在一起。步骤鼓励先预测、再运行、只改一个变量、复测并保存。
- `requiredBlocks` 是练习提示：`anyOf` 列出本课核心积木 opcode，不是对创意、动画质量或科学结论的自动判定。毕业创作仍保留有限的核心积木提示，让孩子选择自己的实现。

## 六阶段与 48 节标题

1. **让想法动起来**：探索员报到、种子去散步、云朵变魔术、给月亮送信、蝴蝶扇扇翅、森林打击乐、修好迷路的小灯、我的自然小剧场。
2. **让作品回应你**：小车停哪里、探索员走地图、跟着萤火虫、小鸟不出界、碰碰花园、白天还是夜晚、会问候的树洞、森林探访记。
3. **设计游戏规则**：收集星光、种子随机旅行、谁先到终点、沙漏挑战、三次机会、开始和再来、分数为什么跳不停、星光收集站。
4. **让角色一起合作**：森林开场信、轮到你说了、一滴雨变阵雨、接住小雨滴、音乐接力赛、花园值班表、找到偷偷加分的雨滴、雨水收集行动。
5. **用程序发现规律**：我的观察清单、更新观察记录、谁是最高的小树、给图鉴找朋友、绘图小机器人、花瓣里的重复、给画法起名字、我的自然数据画。
6. **做自己的作品**：创意从哪里来、先做能玩的一版、把规则记下来、让角色合作、给作品装仪表盘、请家人试玩、修复与升级、我的作品发布会。

## 内容与 Scratch 约定

主题使用自然、声音、交通和家庭观察等孩子熟悉的情境，不依赖外部图片、音频、项目名或 D 盘复制资产。`requiredBlocks` 的 opcode 引用采用 Scratch 3 标准命名。`generate-scratch-curriculum-projects.mjs` 先建立 Scratch 3 项目容器，随后由 `semantic-overrides.mjs` 为全部 48 节课写入按角色编排的可运行参考脚本、练习起始项目、自绘 SVG 角色与脚本路线图；音效课使用本地合成的原创 WAV。参考项目展示本课的基础行为，孩子仍需完成调试、挑战和自己的变化。

里程碑参考项目中有几节使用固定角色和脚本，正文按项目中的名称书写：`s01-l06` 使用小熊、啄木鸟、青蛙；`s01-l08` 使用种子、小鸟、云朵；`s02-l08` 使用探索员、水边、树顶；`s03-l08` 使用玩家、星星；`s04-l08` 使用水桶、云、雨滴；`s05-l08` 使用数据画家、高度列表和画柱条；`s06-l08` 使用发布者、星星。自制积木定义必须从独立的“定义”帽子开始，不能把定义帽子接在绿旗脚本或普通语句后面。

## 提交前 QA

运行 `node scripts/scratch-curriculum/import.mjs` 只读校验全部课程正文、角色、必需积木、96 个项目与图示。再运行 `node scripts/scratch-curriculum/verify-vm.mjs`，它会在本地 Scratch VM 中加载并运行全部 96 个 starter/reference 项目，并对绘图过程、列表数据和雨滴克隆做运行检查。浏览器中的实际渲染、触碰与声音仍按 `docs/SCRATCH_CURRICULUM_ROLLOUT.md` 人工验收。

运行 JSON 解析检查，并确认：

- 恰好 48 个唯一 key；每阶段恰好 8 节；`stageIndex` 为 1–6；`sortOrder` 连续 1–48。
- 前置课时只指向更早的课时，第一节没有前置。
- 每节时长在 20–45 分钟，步骤不少于 6 个，且包含参数、连接、结果和调试描述。
- `requiredBlocks.anyOf` 使用真实 Scratch opcode；它只表达练习意图，不宣称能验证作品创意或运行质量。
- 抽查里程碑课（每阶段第 8 节）以及 `s01-l06`、`s02-l03`：步骤 2 的事件帽子必须位于脚本顶端，步骤 3 只能改一个参数，步骤 4 必须包含“故意制造问题 → 只修一处 → 同输入复测”。
