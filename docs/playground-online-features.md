# 游乐场入口与联网功能说明

更新时间：2026-10-25

## 亲子探索入口

`lib/playground/catalog.ts` 维护公开目录、分组顺序、主推标记与陪玩提示；`app/playground/page.tsx` 展示目录与本地/同步后的探索记录，`playground-shell.tsx` 的导航使用同一目录。

游乐场与主站共用账号和登录弹窗。首页与游戏页的移动导航提供「返回项目」（`/explore`）和主站 `UserButton compact`；游戏页保留返回游乐场、标题、帮助和快捷导航。物理实验室保留完整工作区布局，使用全站桌面顶栏、移动顶栏和底部导航；实验内容前不再添加返回链接、账号等级或徽章栏，也不显示游戏侧栏、游戏标题栏或任务提示。`md` 及以上使用全站顶栏账号入口，避免重复展示登录栏；账号状态变化不切换游戏内容容器。

函数战争移动端将返回项目、返回游乐场、标题、账号和帮助合并为一行导航，为首屏战场与发射操作保留高度；横屏沉浸模式仍由游戏自己的控制栏负责。

- 默认按「一起拼与创造／做个小实验／动脑与编程」浏览，主推七巧板、像素对称、天平称重、迷宫探险和生命游戏。
- 24 点、汉诺塔、数织、记忆翻牌、五子棋、扫雷与函数战争继续在主目录。数独、N 皇后、球排序放在默认折叠的「更多逻辑游戏」；目录搜索包含这些玩法，直达路由保持可用。
- 2048、数字华容道、速算闪电战已从应用删除，包括页面、玩法逻辑、导航、统计聚合、专属徽章与竞速支持；旧路由返回 404，不保留隐藏入口。SEO 元数据、sitemap 与小迪游戏目录同步移除，首页主视觉改用七巧板。首页分类卡数量来自现行公开目录。
- 年龄和时长是选玩参考，不是经过验证的学习效果。卡片默认显示简短简介，展开「陪玩与延伸」后可看家长怎么陪、玩完能做什么。扫雷保留解局学课程链接；五子棋课程及其 playground 工作区接入保持原样。
- 七巧板提供「拼一个 → 说一说 → 用纸片或积木复现 → 自己出题」的轻量提示，拼完自动展开。线下任务不自动记完成、不发放额外奖励，也不新增自由编辑器或上传系统。
- 函数战争目录按当前关卡集说明 10 个战役关与 5 个挑战关；关卡定义仍以 `lib/playground/function-wars-levels.ts` 为准。

## 探索记录口径

首页「我的探索记录」默认折叠，展示已有的累计游玩记录、胜利/解题记录、体验过的玩法，以及每个 STEAM 主题的玩法数和记录次数。删除能力雷达与相对百分比表达，不将游玩次数解释为能力、进度达标或学习效果；同一玩法可计入多个主题，主题次数不能相加当成总局数。

统计只读取现行玩法的存储键；已删除三项的旧成绩不再计入游玩、胜利、体验数、STEAM 主题或小迪画像，也不再合并上传。遗留 localStorage 中这三项仅做清理，不迁入云端。保留玩法继续使用原胜利、解题或去重关卡记录，扫雷仍兼容结构化统计与旧版最佳成绩；旧版只有最佳成绩时按已有成绩条目计数，不据此声称是完整局数。

游乐场探索系列的「全图鉴玩家」门槛随现行目录改为 15 款，其余阶梯保持原值；移除 2048 的「数字传说」，24 点的「闪电速算」仍保留。既有跨游戏荣誉和经验值不重新结算或回收。

## 联网与排行的入口层级

主玩法优先呈现。24 点、汉诺塔、N 皇后、七巧板、像素对称，以及数织、球排序、天平的桌面竞速面板，使用 `RaceOnlinePanel collapsible` 收起空闲入口；数织、球排序和天平已有的移动折叠逻辑保持不变。邀请链接、重连和非 idle 状态自动展开，活动房间不允许收起；面板内容始终挂载，以保留登录回跳、自动加入、恢复和成绩提交。

扫雷原先已默认展示课程标签，排行榜继续作为可选标签，按需读取榜单。五子棋、记忆翻牌、函数战争原有的可选在线模式保留。应用 API 拒绝已删除玩法的旧房间，避免远端清理前仍可恢复对局。

## 联网维护范围

当前状态：联网对战与竞速房间已上线，进入维护期。新增游戏或共享题面前，先补充服务端权威校验、断线/超时生命周期和集成测试；当前产品范围继续冻结。

## 判断口径

这次把「可以加联网功能」限定为当前代码里能公平比较或能安全实时同步的模式：

- 双人规则天然成立的游戏，做实时房间对战。
- 固定关卡或固定参数的单人游戏，做 6 位邀请码竞速房间。
- 已有云端公开成绩口径的游戏，保留/说明榜单联网能力。
- 随机题面、随机棋盘或开放沙盒如果没有共享种子/题面同步，暂不硬接竞速，避免双方玩的不是同一题。

## 已接入的联网能力

| 游戏 | 联网方式 | 当前规则 |
|---|---|---|
| 五子棋 | 实时双人对弈 | 房间码加入，落子由 `gomoku_place_stone` RPC 权威判定 |
| 记忆翻牌 | 实时双人对战 | 房主选主题/难度，翻牌由 `memory_flip_card` RPC 权威判定 |
| 函数战争 | 实时双人回合制对战 | 6 位邀请码加入共享地图；认证 `/fire` API 用共享确定性模拟器重算弹道，再由 service-role RPC 校验 `shot_seq`、轮次、弹药和伤害上限；连续两次超时判负，赛果回写可信在线战绩 |
| 扫雷 | 云端排行榜 | 按难度读取全服前十最佳用时 |
| 24 点 | 竞速房间 | 创建房间时固定同一组牌，用时少者胜，超时/跳过不计胜 |
| 汉诺塔 | 竞速房间 | 同盘数通关，步数少者胜，步数相同比用时 |
| N 皇后 | 竞速房间 | 同棋盘规模手动解题，用时少者胜 |
| 数织 | 竞速房间 | 同一固定关卡通关，用时少者胜 |
| 球排序 | 竞速房间 | 同一固定关卡通关，步数少者胜，步数相同比用时 |
| 天平称重 | 竞速房间 | 同一固定关卡找出假币，称量次数少者胜，次数相同比用时 |
| 像素对称 | 竞速房间 | 同一固定关卡通关，星级高者胜，再比误点、步数、用时 |
| 七巧板 | 竞速房间 | 同一固定关卡完成拼图，用时少者胜 |

竞速房间支持：

- 登录后创建房间，生成 6 位邀请码。
- 复制邀请链接，链接带 `?room=` 参数。
- 另一名玩家输入邀请码或打开邀请链接加入。
- 房间设置固定在创建时，例如关卡 id、盘数、棋盘规模。
- 随机题面类游戏先把题面写入房间设置，例如 24 点牌面。
- 加入后页面自动切换到房间指定设置。
- 玩家完成本局时自动提交成绩。
- 双方成绩到齐后服务端计算胜负。
- 等待房间截止时间为 15 分钟，进行中房间为 30 分钟；到期后由活跃页下一次 4 秒权威读取或后续创建/加入请求触发结算。只有一方提交则该方获胜，双方都未提交则取消且不计胜负。
- 成绩写入由 `submit_playground_race_result` RPC 原子检查数据库截止时间，过期结算由 `expire_playground_race_matches` RPC 完成，浏览器计时不决定胜负。
- 当前没有 heartbeat，因此超时只表示玩家未在截止前提交，不能据此判断具体玩家是否断线。
- Realtime 可用时订阅房间变化，同时始终保留 4 秒权威 API 轮询，推进截止结算并作为断线兜底。
- 并发加入使用 `status = waiting AND guest_user_id IS NULL` 条件更新；只有一个访客成功，失败请求返回 `409`，并记录不含用户和邀请码的结构化冲突指标。

函数战争房间还支持 Realtime + 4 秒权威轮询重连、刷新恢复、回合超时推进、认输结算和单活跃对局约束。客户端只提交武器、表达式和预期序号，不能自行累加胜负或直接执行旧开火 RPC。在线确定性模拟在命中不可破坏障碍（基岩地板、钢板）时同样按爆炸半径结算溅射伤害但不产生弹坑，单发拾取补给箱上限与全场定时补给箱总数（12 个）对齐。

## 函数战争弹道与教学规则

### 坐标、飞行与有效函数

`lib/playground/function-wars-trajectory.ts` 是单人、联网和试射预览共用的函数采样与飞行边界入口；碰撞、伤害和任务结算仍分别由单人 hook 与在线确定性模拟器负责。

- 函数使用炮口局部坐标：原点为炮口，正 x 沿射击方向（联网访客向左），正 y 向上。表达式必须满足 `f(0)=0`，数值容差为 `1e-6`；不再允许以常数偏移把弹道出生点搬到屏外。非零起点或炮口处无定义的输入给出修正说明，不扣弹药或射击次数。
- 每条函数主弹道最多飞行 36 个世界单位，计算的是沿曲线走过的距离；镜像分支各自受限。有效世界范围为 x `[-12,12]`、y `[-7,7]`，弹道在首次到达边界时截断，不能从屏外重返。分裂弹在有效范围内分裂，下落碎片继续接受碰撞和地图边界约束。
- 采样使用有工作量上限的细分与非等距探测；极端高频、未能解析的区间、定义域中断会提前停止，不能把跨越不可计算区域的连线当作实际弹道。界面显示命中、碰撞、边界、距离或计算中断原因。
- 挑战关的函数和常量要求以曲线贡献判断，零乘、相消和只产生常数的函数调用不作为有效使用。实现结合有限化简和采样变化，贡献阈值为 0.04 个世界单位；这是有界数值判断，不是任意表达式的符号恒等证明。有效函数登记还须发生有效攻击、拾取或中继连接，并以实际飞行范围核验。
- 敌人和中继均已清空、但必需的有效函数任务尚未完成时，立即进入 `mission_incomplete` 失败状态，说明缺失目标并允许重开，不继续消耗无意义的剩余射击次数。
- 旧版依赖非零常数出生点的参考解需要调整；15 关的现行参考解由 `hooks/playground/use-function-wars.test.ts` 验证。已有本地通关记录和同步存储键不重置。

### 教学操作与画面

单人默认显示不消耗弹药、不更新进度的试射虚线；使用与发射相同的纯模拟结果，发射时才提交本地游戏状态。可关闭预览，或保留上一发的浅色轨迹作对比。参数工具提供斜线、抛物线和波浪模板；选择模板会替换表达式，修改表达式或退出参数模式后可以自由输入。联网只保留已发射轨迹和输入校验，不提供单人试射预览。

`app/playground/functionwars/feedback.ts` 从模拟器返回的射后状态和事件生成反馈，不另算碰撞或结算。战场显示射程耗尽、边界、掩体材质、伤害、装甲击破、中继与承重坠落；预览若会导致任务未完成、次数用尽或己方坠落，发射前说明后果。成功发射后保留上一发的真实结果，手动修改函数或武器后切回预览，自动换弹不覆盖刚发生的结果。终点标记区分预览与已发射轨迹，最多显示四个有效世界内的点，并避让目标、血条与界面。第二关只对可确认的直线输入提供增大或减小斜率的提示，不猜测任意函数的修改方向。有效函数、中继与剩余次数作为关键任务在战场旁持续可见。

手机优先显示战场、函数输入和有文字的发射按钮；仅突出当前关卡提供的武器。短横屏自动进入页面内沉浸战场，竖屏和桌面也可使用「展开战场」手动进入。沉浸布局覆盖站点导航，战场按可用视口等比例放大，函数输入与发射保持可用；选关、模式切换、数学键盘和详细规则收进可独立滚动的「操作」面板。单人底部当前武器可直接展开选择，模板选定后显示紧凑调参条；战场扣除调参条高度后重新等比例容纳完整世界，避免工具遮住目标。普通模式与沉浸模式共用参数状态。单人结算和联网回合状态仍可见，联网大厅保留登录、加入与建房操作。

`hooks/playground/use-function-wars-immersive.ts` 管理沉浸进退与视口生命周期。「退出沉浸」或 Escape 恢复普通页面及原滚动位置，不重建单人或联网实例，保留关卡、表达式和房间状态。自动进入的会话在转回竖屏时退出；同一横屏内手动退出后不强制再次进入。手动展开会尝试浏览器全屏，失败时保留页面内沉浸；自动横屏仅使用页面内沉浸。布局使用动态视口与安全区，不保证隐藏系统状态栏或浏览器工具栏。

普通模式 Canvas 保持 `12:7` 比例；沉浸模式的 Canvas 铺满扣除发射控制台后的可用宽高。固定 `24×14` 世界始终完整、居中且横纵等比例呈现，额外空间用于非碰撞远景延展，不改变弹道边界或放大命中范围。坐标转换同时使用缩放与居中偏移，避免横屏拉伸。战场采用卡通机械沙盘美术：草原暖阳、峡谷岩层、太空轨道三套远景位于 `public/assets/playground-art/function-wars/v2/`，与透明炮台和补给箱保持统一材质；资源提示词与制作约束见该目录的 `README.md`。背景仅加载当前场景主题，失败时回退程序远景，异步加载完成后重绘，销毁渲染器时解绑回调。图片作为非碰撞远景，前景土层、木纹、钢板和可破坏轮廓仍由实际地图几何绘制，纹理随地形缓存。

五种武器通过弹头、线型和尾迹区别，命中效果区分尘团、木屑和金属火星；炮台带短促后坐、炮口烟及受伤裂纹。单人和联网将发射当时的武器、命中材质作为视觉元数据传给渲染器，不改变弹道、伤害、弹坑或服务端结算摘要，也不随之后的武器选择改写回放。预览和上一发轨迹不触发开火效果。默认显示局部坐标轴、主要刻度和目标标签，细密网格通过控制台按需开启，并限定在实际世界范围内；发射播放期间网格稍淡。`app/playground/functionwars/canvas-overlays.ts` 将可见界面浮层测量为画布局部区域；坐标标签同时避让浮层、炮台和血条，偏移后用引导线关联目标。顶部战斗信息、发射控制台、操作面板和结算卡使用统一战场样式，当前武器与弹药沿用游戏真实状态。减少动态效果设置继续禁用后坐、粒子运动、震动和动态远景。

地表与所有障碍统一合成到缓存地形层，材质不再因可破坏性或太空主题而变成另一种材质。土层使用颗粒与连续层纹，木材使用木板、木纹和斜撑，岩石使用切面，金属使用板缝和铆钉。近地土丘采用埋入地表的宽基部；第 3、5 关保留原坡顶高度并同步调整真实碰撞圆，避免土体仅以圆底贴地。接地土体与地面使用精确几何并集，共用土色填充和连续层纹；地表草线只沿外露轮廓，坡脚不画贯穿横线或独立圆形边缘。悬浮平台保留独立轮廓。装饰地面本身不新增碰撞或承重，实际碰撞仍以关卡障碍为准。

可破坏性单独由锤子／盾牌标记表示，并在单人和联网战场保留文字图例；较大的障碍另显示材质与可破坏状态，细小承重块只保留标记。标记裁切在真实圆形或矩形内部，文字与目标、血条、界面互相避让，完全挖掉的障碍不残留悬空标签。弹坑以不透明擦除形成实际孔洞，重叠坑按并集处理，不挖穿不可破坏障碍；接地的不可破坏土层在真实自身几何内恢复未挖坑的完整土体快照，包含地面以上的坡面。单人孔洞采用弹坑完整半径，联网沿用既有碰撞比例 `FUNCTION_WARS_ONLINE_CRATER_HOLE_RATIO = 0.72`，只在渲染场景转换半径，不修改存储半径、伤害或服务端摘要。缓存键包含全部障碍的形状、材质、可破坏性和画布度量；材质标签锚点随地形键缓存，避免逐帧重复扫描历史弹坑；命中闪光仍独立播放。

### 重试、成绩与关卡节奏

单人重开保留当前表达式供继续修改，切换关卡仍从 `0` 开始。仍在进行的关卡用完选中的特殊弹药时，自动切回无限标准弹并显示提示；已结束的关卡保留最后使用的武器，射击记录始终保留发射时的武器。

`function_wars_stats` 增加逐关 `bestStars` 与 `bestSolutions`。最佳解法包含同一次通关的星数、发数和按序记录的函数/武器；优先较高星数，同星时优先较少发数。`lib/playground/function-wars-progress.ts` 统一校验与比较，`storage.ts` 同步时按完整解法合并，不能把不同局的星数和步骤拼在一起。旧通关记录只显示已通过，不推测历史星数。成绩沿用游乐场存储机制：访客仅本次页面会话内存，刷新清空；登录用户通过已有云端同步持久化，不新建 localStorage 副本。界面可查看并载入最佳解法中的某一发，载入不会自动发射。单人胜负结算等最后一发回放结束后，直接覆盖在战场中央，普通竖屏、桌面与沉浸横屏共用同一结算层。通关显示放大的真实星级、发数、用时和「下一关」，失败显示原因与「重开本关」。卡片高度受战场约束，详情可独立滚动，主要操作固定在卡片底部，避免小屏需要翻页寻找。结算说明三星尚缺的额外目标；最后一关展示本次挑战完成及累计通关、三星进度，提供「返回选关」与「保留函数再挑战」。

第 7 关「残垒清扫」以三座错层排列的受损炮台展示分裂弹的多目标价值。敌人可配置 `initialHp`，有限值按整数约束在 `1..maxHp`，缺省沿用完整生命值；本关三座炮台初始各为 `25/50`，保持标准命中半径与对应支撑，三枚分裂碎片可各命中一座，一发通关。第 11 关保留正弦、π 与中继挑战，目标改为普通炮台，完成一次穿门即可通关。武器全局伤害、分裂散布和联网地图规则不随这两关调整。

### 联网地图版本与发布顺序

新房间使用 `symmetric-canyon-v2`。种子决定对称的高空或低空通道及障碍参数；两类通道要求不同的函数参数，不能用同一条高空抛物线绕过全部地图。双方炮台与修复工事位置保持既有约定，不改变 RPC 的位置计算。`symmetric-canyon` 的生成器继续保留，旧房间的种子、几何和补给顺序不重新解释；新建旧版地图请求会提示刷新。

数据库迁移 `20261025160000_function_wars_map_v2.sql` 扩展 `map_id` 检查约束并更新默认值，不改写已有房间。2026-10-25 已在上述配置实例与退役玩法清理同批执行；回读确认 v1/v2 约束已验证、新房间默认值为 `symmetric-canyon-v2`。应用尚未部署，实际新建房间行为仍取决于运行中的应用版本。其他环境部署创建新版地图的应用之前，须按 [数据库迁移流程](database-psql.md) 获得目标环境与批次授权并应用此迁移。

## 数织联机入口

数织在 `<1280px` 将联机面板收在棋盘前的原生折叠区，空闲时默认仅显示「联机竞速 · 邀请好友」。携带 `?room=` 的邀请页、重连或非 idle 房间状态会展开，活动房间不允许收起。面板始终挂载，以保留自动加入、登录回跳、房间恢复和成绩提交；桌面沿用侧栏面板。

球排序和天平称重在 `<1280px` 使用 `RaceOnlineDisclosure` 收起空闲联机入口；邀请链接和非 idle 状态自动展开，活动房间不允许收起。内容始终挂载，失败返回 idle 后保留展开以便重试。桌面侧栏保持原样。数织仅折叠面板，不再按视口高度压缩棋盘；保留原有宽度约束与线索空间。

数独在 `<640px` 提供可见横向滑动提示，并保留原生横向滚动条、键盘可聚焦的棋盘滚动区域与原格子尺寸。完整九列通过横向滚动访问，不以缩小触控格强行适配。
