# 原生立体课本实现与验收标准

本文维护原生课本的教学映射、书页交互、模型运动、声音、资源所有权与验收要求。课程登记、站内接入、源码来源、旧静态课和嵌入协议由 [课本接入](textbook3d.md) 维护；全站外壳与基础控件遵守 [设计规范](design-system.md)。新增原生课应复用下述标准，不复制一套阅读器和渲染循环。

当前原生入口为 `p1a-1-1`「我们知道的植物」和 `p1a-1-2`「观察植物」。两课各有前置的本课目录和两个正文状态；目录不是新增课时或学习完成条件。其余课仍按接入文档使用旧版。本文描述实现契约与验收门槛，不代表已发布或所有验收已通过。

## 教学内容先于模型与交互

每课先明确“教学目标 → 学生动作 → 可见反馈 → 证据边界”，再确定模型、页面和控件。不能用装饰动画或点击计数代替学习目标；屏幕不能验证的触感、实物大小、户外观察和口述任务，应明确交给真实活动。

| 课程与目标 | 学生动作 | 页面与模型反馈 | 证据边界 |
| --- | --- | --- | --- |
| 第一课：认识身边的植物及生长特征 | 选择大树、小草、花，拖动观察 | 当前示例的观察语句、模型和唯一选中环保持一致 | 选择过示例只表示参与 |
| 第一课：对应树根、树干、树叶 | 点整棵大树 | 同时出现三处部位标签，引线指向真实模型部位；再点可收起 | 不增加逐部位点击顺序或摇晃门槛 |
| 第一课：区分植物与非植物 | 在小草、石头、小狗中选择并说明理由 | 提供可读的文字反馈，关闭声音不丢失结果 | 单题反馈不等于整课掌握 |
| 第一课：迁移到生活 | 说出五种植物，到校园或公园寻找 | 保留任务与观察记录入口 | 不以三个屏幕示例自动判定五种植物任务完成 |
| 第二课：观察颜色、形状并发现叶脉 | 选择叶，观察叶面与叶脉 | 叶脉几何、标签和“我发现”记录对应同一示例 | 示例外观不代表所有植物 |
| 第二课：认识连接关系 | 选择茎，从根向上观察 | 同时对应根、茎、叶及其连接位置 | 不能只显示一根无连接关系的柱体 |
| 第二课：观察花的组成 | 选择花 | 花瓣与花心有可辨认几何及对应标签 | 不把装饰色块当部位解释 |
| 第二课：使用观察方法并记录发现 | 看颜色和形状，真实接触时比较触感和大小，再画一画 | “看、摸、比”的文字说明、观察表与绘画任务 | 屏幕先观察颜色形状；触感需观察真实植物，不能随便尝 |

“记录本次探索”是显式参与记录。答题、点完模型、翻到末页或播放声音不得自动完成；一次阅读会话只调用一次已有完成回调。课程工作区的登录与完成服务继续由原接口负责，不另造知识评分。

## 书体、目录与贴页内容

- 首屏为本课目录，可直接进入任一正文页；正文提供返回本课目录入口。正文页码仍为第 1 / 2 页、第 2 / 2 页，目录不混入正文页数。
- 横屏使用常规左右展开的书体，左页课文、右页模型；竖屏使用同一本书的上下展开布局。书应利用可用高度，同时保留完整页边、植物顶端和必要操作，不用宽扁模型台或缩小文字填补空间。
- 书体以用户认可的旧版为视觉基准：深蓝薄封皮、暖米纸、宽装订凹槽、两侧纸页肩部、薄页叠和上下金色书签，避免中央均匀色带与两块圆角平板。曲面主要位于内折区和外缘，正文所在矩形保持平整；书脊与两页共用连续高度函数，不能让曲面穿出 DOM 文字。采用自然植物颜色和柔和接触阴影。植物直接从纸面展开；选中环是交互状态，不是实体模型底盘。不得把已有方向光投影误记为新增能力。
- 课文、题目、目录、页码、选择控件使用可访问 DOM，并将四角映射到真实书页。正文不烘焙成图片或纹理，分别复用本地常规与粗宋体资源。采用黑色标题、橙色小节、ABC 纸上勾选和透明植物选择标记；答案翻卡有固定占位，选答案立即揭示，也可直接翻看，不因此记录完成。手机主正文为 18px 源字号，仍须验收透视投影后的实际字号与换行。
- 每次按需绘制先更新相机、书体和模型世界矩阵，再用同一帧矩阵投影 DOM、标签和书角按钮，最后绘制 WebGL。旋转、用户缩放、布局切换和翻页不得出现相差一帧的贴页位置。
- 正常 WebGL 模式下完整课文应在纸面可读，不设置页内滚动条，不靠 `overflow: hidden` 隐藏溢出。先精简重复文案与调整排版，不能为小屏直接撤掉贴页。只有渲染失败时使用下述正向文本降级。
- 退出、全屏、声音等必要工具靠近视口边角，受安全区保护。不得恢复占据固定上下高度的工具栏或翻页栏。手机路由外壳的收起与恢复由接入层控制。

## 翻页、选择与部位标签

上一页和下一页入口位于左下、右下书角，使用真实纸面四角的透视投影；不能把按钮固定在屏幕左右边缘或仅跟随一个投影中心点。控件具有明确可访问名称、禁用态及键盘触发方式；首目录不能再向前，末正文不能继续向后。

单次点击才翻页。拖动达到位移阈值、第二指加入、非主指针或 `pointercancel` 都应取消点击候选；拖动、缩放结束不得补触发翻页或模型选择。翻页期间拒绝重复操作并禁用模型选择，退出全屏与旧版回退仍可用。点击、键盘和目录跳转共用同一翻页入口。

选中状态使用一个可复用的静态环，在模型之间互斥移动，文字按钮的 `aria-pressed` 与环同步。不得为选择增加旋转光环、呼吸脉冲或持续 RAF；翻页收起时隐藏，展开后只显示当前模型的环。选择模型和翻页都不自动缩放整本书、移动相机或重置用户视角；用户主动拖动、双指与键盘视角操作可保留。

固定翻页视角不等于锁定用户旋转。相机极角允许 0.1–1.3 弧度，用户可以从俯视转到明显降低的视角，观察树干和书页厚度；方位角允许 ±0.9 弧度。正文非按钮区域可开始旋转，按钮保留点击与键盘语义；正文不再挡住半本书的拖动。尺寸变化重新计算完整取景，但保留用户已选角度和相对缩放，只有主动恢复视角才回默认。初始取景联合书体、植物、书角及卷页运动范围，收紧上方留白，不通过裁切正文或放大植物模型假装扩大书本。

标签数据包括稳定 ID、名称和模型局部坐标锚点，应独立于渲染器。第一课的大树同时标注树根、树干、树叶；第二课按当前示例展示叶脉、根/茎/叶、花瓣/花心。引线锚点先跟随局部变形，再随模型矩阵投影，不能用固定屏幕坐标冒充模型位置。标签限制在模型侧且相互避让，不遮挡正文；保留相应可读状态供辅助技术获取。再次点击当前示例可收起，换示例、翻页、隐藏、渲染失败和卸载均清理；重新显现时不自动恢复旧标签。

## 立体纸模收折与有限动画

`book-motion.ts` 维护一次性的翻页时间线，当前时长 1000ms，复用场景现有的按需 RAF。顺序为局部收纸、沿底边折回、翻动书页、反向展开：

1. `popup-rig.ts` 为每个模型建立固定纸面锚点和底边铰链，借用模型及资源，保留原模型的 X/Y 尺寸与局部变换。
2. 先压缩模型局部 Z 厚度到非零纸层，不压缩模型高度，不把整株植物缩小或沉入纸面。
3. 厚度收拢后，围绕固定底边铰链转回纸面。锚点不随动作漂移，运动应保持模型不穿过纸面。
4. 模型收起后翻纸；低矮卷曲从外缘移向书脊，圆弧与两段直纸连续连接，保留条带弧长，不把纸页整体纵向压扁。初次取景即容纳运动范围，不在途中拉远镜头；到达目标页后逆序展开。书体尺寸、相机距离与用户视角不随翻页变化。

设计参考了 [threejs-animation 技能](https://github.com/CloudAI-X/threejs-skills/blob/main/skills/threejs-animation/SKILL.md) 的有限动画与可见性原则，以及 [spring-bloom 的 popup 示例](https://github.com/amrbody71-commits/spring-bloom/blob/main/js/popup.js) 的“收起完成后翻页、翻页完成后展开”协议。这里只独立实现原理，没有复制代码或示例图像、文字、旁白、音乐；不引入 GSAP/R3F。外部技能以 r186 为例，本站仍使用现有 Three.js 0.185.1。

这是把立体几何收为薄纸轮廓再绕底边转动的近似效果，不是多折痕机构、真实折纸物理或纸张碰撞模拟。验收应检查轮廓、锚点、穿纸与动作顺序，不用“物理正确”描述效果。对实例化模型同样适用，不能为动画逐帧重建几何。

翻页开始即隐藏正文并设为不可交互，覆盖收起、翻纸、展开的完整过程，防止旧纸面上闪出目标页文字；结束后显示目标内容并将焦点移到新标题。尺寸变化、离开视口、后台、重置视角、渲染异常或 context lost 都应结束到已请求的目标页；卸载取消后续工作。`prefers-reduced-motion` 下直接到达目标页，偏好在途中改变也应立即结束。不得用无限过渡、连续相机拉远或整书呼吸缩放制造动感。

按需渲染不等于没有交互动效。`plant-response.ts` 在主动点模型或对应选择按钮后运行一次 1100ms 的衰减轻摆，根部固定，上部枝叶或花梢产生局部形变，整株位置、缩放、书体和相机不动。再次点击从静止基准重新启动同一动作，不累积位移，不建立第二个 RAF；结束帧恢复静止并停止调度。减少动态、隐藏、翻页、尺寸变化、失效和卸载均停止并复原，加载完成时不重放加载前的过时点击。

普通网格在首次需要时取得私有几何副本，复用顶点与法线缓冲；实例化叶片使用仿射近似，草叶底行固定，其他叶片跟随位移与切线旋转。部位标签绑定实际形变或实例矩阵；不只是移动屏幕气泡。副本在阅读器生命周期内缓存并独立释放，原模型几何与材质不被修改或重复释放。该动作是轻风反馈近似，实际自然度和手机 CPU 成本仍需要真实 WebGL 验收。

## 声音

默认完全无声，只有明确点击“开启声音”才创建或恢复 Web Audio，不持久化自动播放偏好。`createBookAudio(onChange, makeContext?)` 保持 `enable`、`stop`、`play`、`dispose` 接口，界面无需持有音频节点。

背景乐为仓库内原创程序合成：G 大调、4/4、88 BPM、32 小节，A/B/A′/B′ 各 8 小节，约 87.27 秒一轮。柔和木质旋律、轻分解拨弦与短低音各有停顿，B 段改变乐句和伴奏方向，再现段改变节奏与结尾；尾句导音回到开头。每个音有柔和起音与归零尾音，不回退为几个持续正弦音或仅降低原短循环的速度和音量。翻页保持短促纸声，树叶交互保持轻沙沙声，文字反馈不依赖听觉。

音频控制器按音频时钟提前 350ms 安排一个小节，不一次创建整首曲子的节点；乐谱最多同时三音，持有声音数量硬上限 24。迟到的调度跳过过期小节，避免集中补播。音频使用独立计时器，不驱动动画或 RAF。

静音立即停止并释放当前及未来已调度音符和交互音；后台、离开可见阅读区、切课、旧版回退与卸载停止。多阅读器只允许一个会话发声，`resume()` 等待期间也独占会话，并防止停止、卸载、变为后台或被另一个阅读器接管后复活。交互音限频并替换上一效果，连点不能叠加。音频设备拒绝时明确显示声音不可用，阅读功能继续可用。

不下载第三方音乐、录音或付费资源，不新增合成依赖。测试只验证乐谱结构、包络与生命周期，实际音色、自然度、音量和循环听感必须试听。

## 性能与资源所有权

| 对象 | 所有权与预算 |
| --- | --- |
| 渲染实例 | 仅可见阅读器加载 Three.js；每实例一个 renderer 和 canvas，目录及正文切换复用，切课/旧版回退/卸载释放。过期动态 import 不得创建实例 |
| 绘制缓冲区 | DPR 上限 1.5，并同时限制约 150 万像素，桌面全屏也受约束 |
| 阴影与效果 | 一盏 512×512 阴影灯，使用当前 Three.js 支持的 `PCFShadowMap`，无后处理；几何状态改变才更新阴影 |
| 场景几何 | 整本场景预算少于 45,000 三角形、135 个网格；实例计入三角形预算，网格数不能等同实际 draw calls |
| 程序纹理 | 纸纤维、布纹共两张 64×64 纹理，由书体释放；不为选中、标签或翻页新增持续生成纹理 |
| 点击动作 | 私有几何仅首次使用时克隆，重复点击复用；实例保持合批，停止恢复原资源与实例矩阵；卸载释放私有副本 |
| 模型与折叠 | 课程提供可复用模型和 `dispose`；几何、材质、纹理与实例缓冲区由场景拥有。折叠 rig 只借用并恢复附着关系，不重复释放模型资源 |
| 调度 | 静态无 RAF；拖动、选择、尺寸变化、有限翻页及点击轻摆才绘制；翻页、标签和选择共享一个调度器，无各自循环 |
| 清理 | 监听器、Observer、RAF、计时器、GPU 资源、音频节点和 renderer 在所有权结束时释放；重复 dispose 安全，无模块级 GPU 缓存 |

开发模式可通过 canvas 的 `textbookDiagnostics()` 读取资源数、绘制计数、首帧等待、绘制 CPU 时间和拖动帧间隔；诊断信息不进入产品界面。CPU 时间不等于 GPU 时间，首帧等待不等于正式 Web Vitals TTI；几何预算和 mock 生命周期测试不证明真机帧率或全册性能改善。

## 触摸、降级与验收

以下是每次变更必须核对的验收要求。按实际运行结果报告通过、失败或未验证，不以本清单存在或测试文件存在作为通过证据。

| 验收层 | 必须观察的结果 |
| --- | --- |
| 教学与导航 | 两课均从目录进入两个正文页并返回目录，页码正确；内容与所选模型一致；记录不会自动触发或重复回调 |
| 同帧布局 | 正文、选择按钮、底角翻页及标签与纸面同帧对应；旋转和用户缩放后仍可读、可点，页顶、植物顶端和按钮不越界 |
| 翻页与选择 | 收纸→底边折回→翻纸→展开，锚点固定且不穿纸；相机和整书没有自动缩放；静态选中环互斥；点选局部轻摆、根部固定、标签随动；动作结束空闲没有新帧 |
| 真实手机 | 至少核对 390×844 竖屏、844×390 横屏及参考 873×412 横屏，另查 1440×1000 桌面；实测文字换行、完整可见、无页内滚动，触控有效命中区投影后至少 44×44 CSS 像素，且不与相邻操作互相遮挡 |
| 手势与辅助操作 | 单击、拖动、第二指加入、双指缩放、取消指针和连点互斥；正文空白和文字区域可上下/左右拖动，按钮不会误触旋转；键盘与读屏可操作目录、选择、翻页和退出；翻页后焦点落到新标题 |
| 沉浸与切换 | 原生 Fullscreen API 拒绝仍能页面内全屏；安全区、Escape、跨断点祖先隐藏、切课及卸载正确恢复滚动、焦点和 inert 状态；多实例不争用会话 |
| 中断与降级 | 减少动态效果、翻页中旋转屏幕、后台、离开视口、WebGL 创建失败、context lost 和渲染异常都结束到目标页且清理工作 |
| 资源与性能 | 在同设备、同画质和可比场景下检查初次进入、拖动、反复切页/切课/全屏后的资源和 JS 堆趋势；draw calls 包含阴影 pass，不把源码网格数当 GPU 实测 |
| 音频 | 默认无声、主动启用、静音、后台、卸载、多实例与 pending resume 正确；试听完整 A/B/变化再现与循环衔接，确认音量、音色和注意力占用 |

WebGL 失败时固定保留正向可访问课文、题目、目录和必要操作，允许整体滚动；退出全屏与翻页可用。显隐、缩放或后续翻页不能重新启用已失效的透视 DOM；用户明确重载 3D 后才创建新渲染实例。正常 WebGL 模式不能以降级布局掩盖正文溢出。

`lib/textbook3d/native/`、`components/features/textbook3d/native/` 和 `app/project/[id]/textbook-immersive.test.tsx` 是相关单元、DOM 与生命周期测试入口。模拟设备与边界替身不能证明真实布局或听感；新增目录、课程、标签、折叠和点击动作必须在当次测试中明确覆盖。书体结构参考已交付的 `public/textbook3d/v1/shared/chunk-LWFFMK3R.js` 与用户原版截图，独立重建可维护几何与排版；没有修改带哈希产物，也不声称恢复原工程。

`scripts/textbook3d/measure-native.mjs` 是本地真实浏览器测量入口，可配置 `TEXTBOOK_PREVIEW_URL`、`TEXTBOOK_BROWSER_EXECUTABLE`、`TEXTBOOK_EVIDENCE_DIR`。运行前应核对其导航步骤与本课目录、两正文及第二课一致；旧的双页脚本不能直接作为新结构已验收的证据。浏览器必须支持正常沙箱，不关闭沙箱重试，也不据此触发远端 CI。

`scripts/textbook3d/preview-book-geometry.ts` 可从应用同源几何导出 CPU 投影，用来检查构图和折叠轮廓。SVGRenderer 不支持真实 WebGL 阴影、PBR 与深度缓冲；任何手工排入课文的示意图也不是 React DOM 截图，不能证明字体换行、材质、阴影或触控正确。输出必须标明证据类型。
