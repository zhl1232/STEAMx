# 物理实验室

物理实验室位于游乐场，供学生从现象出发动手探究。它提供跨学段的精选实验，不是小学到高中的完整课程，也不替代真实实验、教材或教师对学习成果的判断。学段是建议；任务难度使用「入门探索 / 规律探究 / 综合挑战」，不把三个难度机械等同于三个学段。

## 界面布局

实验室品牌文案以 `lib/brand.ts` 为准，对外统一使用「创探空间」，页脚沿用主站 `SiteFooter` 的品牌定位；独立页面标题、介绍、导出报告及下载文件名保持同一名称，不另设实验室品牌口号。已有存储键、备份协议标识与嵌入消息类型继续兼容原格式。

主站页头将实验室标题和记录状态并列呈现，手机上自然换行。同步失败只显示一个可操作提示，提供重试及可展开的错误详情；设备存储不可用时仍明确提示导出备份，不把离线状态显示为云端保存成功。

实验室默认打开目录。自由搭建、现象探究和电路引导任务在同一目录中按主题分组，以标签说明操作方式；不再把目录作为工作台里的临时面板。顶部并列学段与搜索，桌面使用主题侧栏与图文列表，宽度足够时显示两列。手机将主题改为可横向滚动的选项，不挤压实验内容。整张实验卡片是可访问的真实链接，点击缩略图、标题或说明即可进入，支持键盘、右键和新标签页；不另设「开始探索／开始任务」按钮。标题、建议学段与现象说明区分层级；原有筛选、分页和返回时的状态保留规则不变。

目录缩略图复用实验模型默认参数的静态示意，并按实验缓存；自由搭建提供对应的电路、光路和弹簧示意。预览移除微小文字、焦点与探针交互属性，独立命名 SVG 引用，不播放、不发声、不修改实验参数或记录；实际操作与读数仍在实验工作区进行。

工作台、参数区、实时读数、电路任务、记录和备份弹窗统一使用主站字体与语义颜色。实验中只有一处「实验目录」返回链接；自由搭建的操作栏还提供新建、保存、加载和帮助，现象探究使用自己的观察记录操作。目录不显示工作台操作栏，嵌入时不再重复显示实验室名称；手机图标按钮仍提供完整可访问名称。主要操作保持可点击面积，辅助文字不再沿用原独立演示页的微小字号；手机采用自然纵向布局，桌面为画布和参数面板保留合理比例。

## 目录范围

当前提供十一个主题，包含三个自由搭建工作台和六十三个参数化实验，共六十六个互动入口。计数指实验入口，不指课时或课程覆盖率；部分实验为明确标注的定性比较。

统一目录可组合筛选小学科学、初中物理、高中物理、主题及关键词。六十六个实验与十八项电路引导任务合并分页，每页最多十二个入口，数量分开标注，不把任务冒充新增实验模型。电路、光学、力学自由搭建作为普通实验条目出现；电路任务直接归入「电路与电功率」主题，不再提供额外的电路专项目录入口。任务的学段建议独立声明，不把难度标识机械转换成学段。

## 地址、返回与工作区状态

主站统一使用 `/playground/physics-lab` 及查询参数，每个实验、工作台和电路任务都有可复制、刷新直达、在新标签页打开的真实链接：

- 目录：`/playground/physics-lab`。
- 现象探究：`/playground/physics-lab?experiment=plane-mirror`。
- 自由搭建：`/playground/physics-lab?experiment=circuit`（也支持 `optics`、`mechanics`）。
- 电路任务：`/playground/physics-lab?experiment=circuit&lesson=divider`。
- 筛选：`stage`、`topic`、`q` 与从 1 开始的 `page`。进入实验时带上来源筛选，返回目录时恢复该位置。搜索最长 120 个字符。

目录与实验切换、学段、主题、分页写入浏览器历史；搜索输入替换当前记录，避免每个字占一次后退。浏览器前进后退恢复地址对应的目录或实验；点击目录返回不会依赖用户是否从目录进入。无效实验或筛选安全回到有效目录状态。查询参数仅包含公开导航信息，不放账号、观察文字或搭建数据。

主站由父页面使用 Next 支持的原生 History API 管理地址，iframe 地址保持稳定；子页面不向自己的会话历史插入导航项。导航消息检查同源、具体 iframe/父窗口和文档标识，旧文档消息不得改变当前地址；挂载、加载及重复握手均能恢复当前地址。地址变化不重建账号工作区、不重新初始化记录同步。独立静态版由自身历史管理相同查询参数。

同一工作区存续期间，各现象实验保留参数、时刻和探究层级，自由工作台保留搭建与撤销记录。电路任务始终从最新任务记录恢复，避免旧导航快照覆盖新接线。刷新直达会打开对应实验；未保存的自由搭建和参数草稿不保证跨刷新保存，仍需主动保存观察或搭建。换号沿用主站重建工作区规则，不复用其他账号的草稿。任务记录已满而无法新建时显示原因并恢复有效目录/原页面地址，不留下与画面不符的任务链接。

打开目录暂停动画和声音，并屏蔽隐藏工作台的编辑快捷键。实验间切换不创建项目关联、不改变账号或成长奖励口径。

## 学段与教学内容

学段允许交叉：小学侧重声音、光、冷热、磁铁、简单电路和力与运动的观察；初中增加定量的声光热、压强浮力、电功率和电磁探究；高中增加运动学、能量动量、电场磁场、感应、振动与波的模型分析。筛选表示建议使用范围，不是教材逐章对齐或年级教学安排。

| 主题 | 可操作内容 | 教学递进示例 |
|---|---|---|
| 测量与读数 | 天平质量差、量筒排水法与密度计算 | 两次读数求差 → 单位换算 → 测量有效性 |
| 声音 | 频率、振幅、纯音试听；回声测距；不同介质与真空 | 高低与强弱 → 传播条件 → 往返时间与距离 |
| 光与成像 | 自由光线与透镜；平面镜与凸透镜成像、影子、折射全反射、色散与加色 | 观察光路与颜色 → 实像与虚像 → 折射与薄透镜定量 |
| 冷热与物态 | 加热、热交换、六种相变与蒸发、热膨胀、传导对流辐射、理想气体 | 冷热与传热方向 → 热量守恒、潜热 → 热流率与状态方程 |
| 磁与电磁感应 | 磁铁指南针、通电导线、粒子与导体受力、棒与线圈感应、铁芯、交流发电、变压器与换向器 | 电流与磁场 → 力和感应方向 → 发电与电动机原理 |
| 电路与电功率 | 自由接线与串并联；电表、滑动变阻器、导电材料、电阻率与电源测量、电功率 | 闭合回路与仪器接法 → 欧姆定律 → 功率与测量拟合 |
| 力与运动 | 弹簧滑轮、推力摩擦、杠杆、运动学、矢量合力、相互作用力与超失重 | 运动与平衡 → 受力和运动图像 → 动力学建模 |
| 压强与浮力 | 固定位置受力与释放浮沉、受力面积、液体压强、液压机 | 面积与压强 → 深度、密度与平衡 → 帕斯卡原理及功守恒 |

| 电场与电容 | 两点电荷场强及电势、平行板电容器、RC 充放电 | 电场叠加 → 电容与储能 → 时间常数与能量核算 |
| 振动与波 | 行波、双缝干涉、单摆、弹簧振子、受迫振动共振与多普勒 | 振动与传播 → 周期与能量 → 驱动频率与相对运动 |

每个参数化实验有可调参数、实时读数、可展开的原理与模型范围、三层探究提示以及可选观察记录。连续量使用滑块与精确数值；材料、接线、过程等离散量使用带名称的选择框，输入与备份验证同时限定允许值，观察报告输出选项名称。动态实验支持播放、暂停、时间拖动与重置。「放大图示」暂停当前过程，打开可缩放、滚动和键盘访问的当前时刻图示，便于手机查看刻度与光路；关闭后参数与时刻保持不变。声音仅在主动点击试听后发声；离开实验或页面隐藏时停止。探针可拖动，也可以通过带标签的滑块和数值输入控制。

杠杆从水平静止释放，配重、杆的倾角、竖直重力箭头与水平力臂随过程更新；提供左侧下降、保持平衡、右侧下降三组可修改的对照，选取对照会暂停并回到起点。液压机显示两活塞的相反位移，提升实验显示物体与绳的运动，读数区分当前累计量与全程目标量。对流及蒸发使用示踪动画，只展示方向与交换；控制条、放大图示及观察记录用「示意进度」百分比，不将播放位置称为真实物理时间。

补充的基础内容包括平面镜虚像、不同介质与真空中的声音、三棱镜色散、RGB 加色、自然对流、热辐射、蒸发因素及六种物态变化。电学提供电表串并联、极性和量程读数、滑动变阻器四接线柱、材料导电性与电阻率、RC 充放电及电源电动势与内阻测量。力学与电磁增加矢量合力、作用力与反作用力、超失重、受迫振动与共振、多普勒效应、磁铁进出线圈、交流发电、导体受力、换向器原理及铁芯效应。

电表和滑动变阻器是专门的接线选择练习，未扩充自由搭建求解器的元件类型。质量与密度模型提供理想读数比较，不模拟真实天平调平、砝码操作误差；电源参数拟合使用明确列出的五组理想负载测量，不冒充学生亲自采集的数据。原有实验参数结构保持不变，补充模型使用新 ID，旧观察与备份仍可恢复。

自由搭建的组件、接线端点和线路拐点在编辑及动画重绘后保留键盘焦点，支持连续操作。进入主题实验时，自由搭建的删除、撤销和取消接线快捷键停止响应，返回后保留原场景与撤销历史。

电路保留三项轻量入门活动和十八项专项任务；这些数量只描述电路模块。完成探究记录不等于系统认定掌握知识。教师可要求先预测、只改变一个变量、记录对照结果，再解释与讨论。

## 科学模型边界

读数使用 SI 单位计算，界面换算为 μC、mC、g、L、mA 等常用单位；重力加速度取 9.81 m/s²。图形是教学示意，颜色不是物理量；各实验声明的箭头、轨迹和时间缩放不作为测量尺。

- 自由搭建电路采用单理想电源、恒定电阻灯泡，不模拟灯丝温度或烧毁。短路停止计算，不能将其读数理解为真实电流为零。
- 电场为点电荷叠加，屏蔽近中心奇点；磁铁使用外部偶极近似。通电导线为无限长直导线，忽略地磁场；磁场箭头归一化表示方向。
- 磁场中的粒子初速度垂直磁场；不计重力及辐射，磁场力不做功。正磁场指向纸外。
- 导体棒在理想闭合导轨中运动，忽略电感；逆时针电流为正，到边界实际停止后感应电流归零。暂停展示运动快照，若要研究停止运动应把速度设为零。
- 声音是正弦纯音，振幅为相对值，试听不作为声压级测量。横向行波与声音纵波分别呈现，不把声波说成横波。
- 加热忽略散热与容器吸热，80℃ 停止，无相变。热交换使用简化集总模型，时间尺度只解释趋势。
- 推力实验从静止开始，最大静摩擦与滑动摩擦使用同一系数。浮力显示外力固定位置时的重力、浮力和释放初始趋势。
- 杠杆为无质量刚性杆和固定在杆上的质点配重，重力保持竖直；控制量是配重到支点的距离，倾斜后的力臂为其水平投影。按 `Iα=τ` 固定小步长积分，忽略阻力；初始力矩相等时保持水平。达到 ±35° 时由止挡提供反力矩并停止，不反弹，不把停止误称为两侧重力矩平衡。播放采用半速；原有参数键及观察记录保持兼容。
- 自由下落截止首次触地前，不模拟反弹。一维碰撞无外部冲量；恢复系数控制动能损失，只有左车追近右车时发生碰撞。
- 折射不模拟色散或菲涅耳光强。原自由搭建使用近轴光线与理想弹簧、滑轮模型。滑轮轮辐角度跟随绳的实际位移，质量平衡或到达画布边界时不再自行转动。
- 新增凸透镜使用薄透镜、近轴模型；物体处于焦点时不显示有限像距，虚像不能接在光屏上。影子采用点光源，不模拟半影；回声忽略风和吸收，以空气温度估算声速。
- 相变实验使用标准大气压下纯冰、水的定值比热与潜热，累计比吸热量控制从 −20℃ 冰到 100℃ 水蒸气的过程；不将蒸发等同于沸腾。热膨胀图放大长度变化；热传导是稳态一维导热，不是物体逐渐升温的瞬态模型。理想气体使用绝对温度、绝对压强和相互独立的平衡态，不模拟绝热过程。
- 匀加速允许反向运动；抛体忽略空气阻力、截止首次触地，地面零初速时过程时长为零。圆周运动是给定速率的匀速圆周运动；单摆限于不超过 10° 的小角度近似；水平弹簧振子不计阻尼。
- 固体压强显示平均值，液体静压区分表压和绝对压强；液压机为外部给定的 10 s 匀速行程，不由输入力预测运动，不计液柱重力压差、摩擦及可压缩性。活塞直径随面积平方根变化，两侧位移使用相同尺度，排开与增加的液体体积相等。提升功率采用给定高度和用时的匀速理想提升，忽略启停动力学，效率仅用于能量核算；结束后累计量不再增加。电热以恒定电阻计算。
- 原有平行板电容器保持连接恒压电源，不模拟边缘场或充放电暂态；RC 暂态使用独立实验。原有螺线管是长空气芯线圈，铁芯效应使用独立实验，不预测吸力。变压器仅使用理想交流有效值及纯电阻负载，不适用于稳恒直流。
- 双缝采用单色相干光、远场近似，只显示干涉强度，不含单缝衍射包络。

- 释放浮沉使用立方体的实际浸入比例计算浮力，配合线性阻力和固定小步长数值积分；阻力用于表现趋于平衡，不对应真实材料的时间标定。粗糙透水底面接触时仍保留浮力，支撑力补足受力平衡。原有「物体为什么会浮起」继续提供固定位置的受力比较。
- 对流与蒸发只给定性趋势，不输出虚构速率。对流示踪仅在原模型具有浮力驱动趋势时循环；稳定分层、零温差、零重力或固体不显示流动。蒸发显示分子逸出与返回，等温饱和时仍有双向交换，液面不随示踪下降；粒子数、数量比、速度和播放进度都不代表真实通量或质量变化。辐射使用开尔文四次方和漫射灰体近似；相变补充使用人为进度而非时间，水的冷却、熔凝、沸腾和液化定量计算，升华与凝华只讨论物态及热量方向。
- 电表错接、反偏和超量程分别提示，受保护的短路不显示零电流。滑动变阻器模型超过 2 A 保护断开。电阻率模型恒温、串联 1 Ω 保护电阻，玻璃值仅为示例。RC 在 5τ 保留真实快照，不把尚未严格为零的电流强制清零；电源 U–I 拟合在数据无跨度时不可用。
- 受迫振动使用有阻尼的从静止开始的解析解，展示至 30 s，不保证已经进入稳态。多普勒仅限一维亚声速，区分频率预测与波前实际到达。线圈磁通为显式近似空间分布；铁芯使用可逆饱和近似，不预测吸力或磁滞。交流发电为给定转速、纯电阻负载；换向器实验为外力带动的角度演示和瞬时力矩计算，不预测电机启动、转速或效率。

当前仍是精选实验，未覆盖天体运动、完整波动光学、自感与传感器、热学微观模型及现代物理等完整序列；后续新增内容沿用主题目录，不通过增加任务编号宣称覆盖教材。

实验覆盖核对参考[《中小学实验教学基本目录（2023 年版）》](https://www.ncet.edu.cn/u/cms/www/202311/241430136xjv.pdf)，不宣称完成新版课标逐条达标审核。模型核对参考 OpenStax 的[平面镜](https://openstax.org/books/university-physics-volume-3/pages/2-1-images-formed-by-plane-mirrors)、[热传递](https://openstax.org/books/university-physics-volume-2/pages/1-6-mechanisms-of-heat-transfer)、[浮力](https://openstax.org/books/university-physics-volume-1/pages/14-4-archimedes-principle-and-buoyancy)、[电学仪器](https://openstax.org/books/university-physics-volume-2/pages/10-4-electrical-measuring-instruments)、[RC 电路](https://openstax.org/books/university-physics-volume-2/pages/10-5-rc-circuits)、[受迫振动](https://openstax.org/books/university-physics-volume-1/pages/15-6-forced-oscillations)与[线圈力矩](https://openstax.org/books/university-physics-volume-2/pages/11-5-force-and-torque-on-a-current-loop)章节。杠杆释放模型参考[力矩与垂直力臂](https://openstax.org/books/university-physics-volume-1/pages/10-6-torque)及[转动动力学](https://openstax.org/books/university-physics-volume-1/pages/10-7-newtons-second-law-for-rotation)。

## 保存与跨站迁移

主站访客记录使用独立的本机缓存；登录用户按账号缓存并自动同步私密实验记录。缓存键为 `steamx:physics-state:guest` 和 `steamx:physics-state:<userId>`，包含备份、基础版本及未同步标记。切换账号立即重建工作区并废弃旧请求与会话消息，不把游客或其他账号的记录自动归入当前账号。用户可主动「导入游客记录」或「导入原有本机记录」，原数据保留；损坏缓存保留原始内容并显示错误。

云端 `physics_lab_states` 每账号一行，使用本人 RLS、现有 `save_progress` 数据库触发器及 API 互动权限。GET/PUT 均从主站会话取得用户，PUT 的账号标识只用于拒绝换号后的迟到请求，不决定写入归属。接口验证备份格式、模型、UTF-8 大小与版本；版本不匹配返回冲突，保留本机修改，由用户主动合并。保存串行执行，网络失败不显示成功，也不丢弃待同步记录。

合并或导入向 iframe 下发记录时，同时校验文档、会话、子文档版本及请求标识；确认应用前暂停云端写入。期间发生新编辑则取消这次替换，保留当前实验记录并提示重试。未确认的合并不得提前推进基础云端版本。刷新 iframe 重新握手，活动场景、参数与未保存的自由搭建不会因普通记录合并而被替换。

表由 `supabase/migrations/20261023160000_physics_lab_states.sql` 创建。2026-10-25 已获授权在当前配置的生产实例执行，限定迁移与追踪记录已原子提交；应用部署后才启用线上云端存档。其他环境仍须按 [数据库迁移规范](database-psql.md) 执行经授权的迁移。表尚未部署或接口不可用时，界面显示未同步并保留设备记录，不能据代码存在声称线上同步已启用。

项目详情到具体实验的链接属于后续内容关联；本次不创建项目关联、不提交公开探索记录、不改变项目完成或奖励条件。静态独立运行仍使用原浏览器存储；它与主站账号缓存隔离，可通过明确导入或备份文件迁移。

页脚「备份与迁移」导出版本 1 的 `steamx-physics-backup` JSON，主站从当前账号/游客工作区导出，独立版从以下本地键导出：

| 键 | 内容与限制 |
|---|---|
| `steamx-physics-experiments-v1` | 最多 30 个已保存的自由搭建实验 |
| `steamx-learning-notebook-v1` | 最多 30 份电路任务记录，每份最多 20 次读数 |
| `steamx-topic-observations-v1` | 最多 120 条主题观察，含参数、时刻、探究层级及文字 |

先保存尚未保存的自由搭建，再在旧站导出、到新站导入。文件最大 8 MB。导入先校验，再合并；相同记录跳过，冲突 ID 重命名并更新任务引用，不覆盖同名记录。合并超限时拒绝写入，写入失败尝试恢复三个原键。存储不可用时保留当页内存并显示状态，须及时导出；备份只包含已保存的实验、任务及观察，不包含尚未保存的自由搭建场景。报告和 JSON 均由用户主动下载，不自动公开。

重复导入同一备份时，已因冲突重命名的记录及其任务引用也参与内容去重；生成的 ID 遵守恢复校验的长度限制。主题观察和电路记录本的「撤销删除」只恢复最近删除的项目，保留之后新增的记录、当前任务和已修改的解释；达到对应数量上限时拒绝恢复。导入后重新读取记录会清除旧的删除撤销状态。

迁入 `public/` 意味着正式发布创探空间后实验室静态代码可公开访问；其中不包含账号秘密或学生记录。原 Sites 预览的访问控制保持独立。正式站发布遵循根 `AGENTS.md`。

导出目标必须为空。将导出内容用静态服务器托管，或复制到原 Sites 项目的 `dist/` 后按该项目的 `.openai/hosting.json` 打包发布；无需更改运行时代码。不要直接维护预览副本。

模型检查包括守恒量、方向与单位、零值、控制边界、成像奇点、相变平台及图示随时间变化；DOM 检查包括目录筛选分页、参数校验、播放暂停、探针拖动、观察恢复和备份合并回滚，覆盖全部参数化实验的备份往返。主站测试覆盖账号隔离、离线保存、版本冲突、迟到消息、替换确认、iframe 重载、旧本机数据导入、共享账号导航与主题同步；数据库验证应覆盖 RLS、限制账号直写拦截、比较版本后更新及级联删除。

轻量 DOM fixture 不渲染、不做布局或真实命中测试，不能代替浏览器验收。CI 的浏览器回归覆盖连续键盘操作、隐藏工作台保护、删除后新增再撤销、备份下载与重复导入，以及手机和桌面视口的主站入口、目录、全部实验入口、iframe 高度与横向溢出。人工浏览器验收仍应覆盖真实触屏拖线与开关点击、实际声音输出及从旧域导出后在新域导入。
