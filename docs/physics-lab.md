# 物理实验室

物理实验室位于游乐场，供学生从现象出发动手探究。它提供跨学段的精选实验，不是小学到高中的完整课程，也不替代真实实验、教材或教师对学习成果的判断。学段是建议；任务难度使用「入门探索 / 规律探究 / 综合挑战」，不把三个难度机械等同于三个学段。

## 主题与教学范围

当前提供七个主题，包含三个自由搭建工作台和十五个参数化实验。计数指实验入口，不指课时或课程覆盖率。

| 主题 | 可操作内容 | 教学递进示例 |
|---|---|---|
| 电路与电场 | 手动画线、灯泡与开关、串并联、电流与功率；两点电荷场强及电势 | 闭合回路 → 控制变量与欧姆定律 → 电路分析、电场叠加 |
| 光 | 镜面反射、凸凹透镜；折射与全反射 | 观察光路 → 法线与角度 → 斯涅尔定律及临界角 |
| 声音与波 | 频率、振幅、纯音试听；横向行波与质点振动 | 高低与强弱 → 波速、波长 → 波动表达式 |
| 冷热与热量 | 恒定功率加热、比热容；两份水热交换 | 冷热变化 → 比较质量与材料 → 热量守恒 |
| 磁与电磁 | 磁铁及指南针；通电直导线；带电粒子；运动导体棒感应 | 同名相斥、异名相吸 → 电流产生磁场 → 洛伦兹力与法拉第定律 |
| 力与运动 | 弹簧、滑轮；推力与摩擦；杠杆；浮力 | 改变运动、平衡与浮沉 → 受力与定量关系 → 动力学建模 |
| 能量与动量 | 自由下落中的机械能；一维碰撞 | 能量转化 → 动量守恒 → 区分弹性与非弹性碰撞 |

每个参数化实验有可调参数、实时读数、可展开的原理与模型范围、三层探究提示以及可选观察记录。动态实验支持播放、暂停、时间拖动与重置。声音仅在主动点击试听后发声；离开实验或页面隐藏时停止。探针可拖动，也可以通过带标签的滑块和数值输入控制。

电路保留三项轻量入门活动，较完整的十八项电路任务收在更多任务中；这些数量只描述电路模块。完成探究记录不等于系统认定掌握知识。教师可要求先预测、只改变一个变量、记录对照结果，再解释与讨论。

## 科学模型边界

读数使用 SI 单位计算，界面换算为 μC、mC、g、L、mA 等常用单位；重力加速度取 9.81 m/s²。图形是教学示意，颜色不是物理量；各实验声明的箭头、轨迹和时间缩放不作为测量尺。

- 电路采用单理想电源、恒定电阻灯泡，不模拟灯丝温度或烧毁。短路停止计算，不能将其读数理解为真实电流为零。
- 电场为点电荷叠加，屏蔽近中心奇点；磁铁使用外部偶极近似。通电导线为无限长直导线，忽略地磁场；磁场箭头归一化表示方向。
- 磁场中的粒子初速度垂直磁场；不计重力及辐射，磁场力不做功。正磁场指向纸外。
- 导体棒在理想闭合导轨中运动，忽略电感；逆时针电流为正，到边界实际停止后感应电流归零。暂停展示运动快照，若要研究停止运动应把速度设为零。
- 声音是正弦纯音，振幅为相对值，试听不作为声压级测量。横向行波与声音纵波分别呈现，不把声波说成横波。
- 加热忽略散热与容器吸热，80℃ 停止，无相变。热交换使用简化集总模型，时间尺度只解释趋势。
- 推力实验从静止开始，最大静摩擦与滑动摩擦使用同一系数。杠杆显示水平位置力矩和转动趋势；浮力显示外力固定位置时的重力、浮力和释放初始趋势。
- 自由下落截止首次触地前，不模拟反弹。一维碰撞无外部冲量；恢复系数控制动能损失，只有左车追近右车时发生碰撞。
- 折射不模拟色散或菲涅耳光强。原自由搭建使用近轴光线与理想弹簧、滑轮模型。

当前仍不是完整知识体系。例如物态变化的完整过程、压强与气体、圆周与天体运动、复杂振动与干涉、交流电及现代物理并未形成完整实验序列；后续新增内容沿用主题目录，不通过增加任务编号宣称覆盖教材。

## 保存与跨站迁移

数据保存在当前浏览器的当前 origin，不随登录同步，也不自动跨域传输。嵌入与独立打开在 STEAMX 同源时共享记录。运行时不读取 STEAMX 登录信息，不接入现有课程完成奖励。

页脚「备份与迁移」导出版本 1 的 `steamx-physics-backup` JSON，包含以下本地键：

| 键 | 内容与限制 |
|---|---|
| `steamx-physics-experiments-v1` | 最多 30 个已保存的自由搭建实验 |
| `steamx-learning-notebook-v1` | 最多 30 份电路任务记录，每份最多 20 次读数 |
| `steamx-topic-observations-v1` | 最多 120 条主题观察，含参数、时刻、探究层级及文字 |

先保存尚未保存的自由搭建，再在旧站导出、到新站导入。文件最大 8 MB。导入先校验，再合并；相同记录跳过，冲突 ID 重命名并更新任务引用，不覆盖同名记录。合并超限时拒绝写入，写入失败尝试恢复三个原键。存储不可用时主题观察暂留内存，须导出观察报告；整个站点备份只包含成功保存的数据。报告和 JSON 均由用户主动下载，不自动公开。

迁入 `public/` 意味着正式发布 STEAMX 后实验室静态代码可公开访问；其中不包含账号秘密或学生记录。原 Sites 预览的访问控制保持独立。正式站发布遵循根 `AGENTS.md`。

```sh
pnpm run test:physics-lab
pnpm exec vitest run app/playground/page.test.tsx app/playground/physics-lab/physics-lab-frame.test.tsx
pnpm run type-check
node scripts/export-physics-lab.mjs /tmp/physics-lab-export
```

导出目标必须为空。将导出内容用静态服务器托管，或复制到原 Sites 项目的 `dist/` 后按该项目的 `.openai/hosting.json` 打包发布；无需更改运行时代码。不要直接维护预览副本。

模型检查包括守恒量、方向与单位、零值和边界；DOM 检查包括选主题、参数校验、播放暂停、探针拖动、观察恢复和备份合并回滚。轻量 DOM fixture 不渲染、不做布局或真实命中测试，不能代替浏览器验收。人工浏览器验收应覆盖桌面与手机布局、实际拖线与开关点击、声波试听、iframe 高度、下载及从旧域导出后在新域导入。
