## 开售前的关闭条件

| 检查项 | 所需证据 |
|---|---|
| 权益全周期 | 真实开通、跨自然月、到期、续购、取消和退款后的资格及余额符合计费文档，不把管理员或测试账户当付费客户 |
| 收款与退款 | 主体、支付产品审批、使用场景、真实收款及原路退款闭环分别核实；不以接口代码或申请截图代替交易证据 |
| 人工履约 | 核验既有拟售方案中的账号对应、24 小时人工开通，以及工作日 9–18 时（北京时间）、2 工作日首次回复的实际承接能力 |
| 退款条款 | 保留待核验口径：7 日内未使用付费权益全退，其他按实际履约依法核实并说明；确认后 5 工作日内发起原路退款。正式条款需与实际能力和适用要求核对，不把本表当新发布的法律承诺 |
| 页面验收 | 真实桌面/手机查看说明、状态、到期与反馈；未开放时无可误点的购买或支付入口 |

以上是关闭任务需要的证据，不代表本次已履约或验收通过。商城渠道和材料采购不在本页重复定义，见 [商城决策](STORE_CHANNEL_FULFILLMENT_DECISION.md)。
