## 改动

1. 聊天在整段回复安全清洗完成后立即启动语音结束输入，不再等待附件选择、记忆维护、计费和落库。完成 Promise 当场挂接错误处理，只结束一次；文本保存与音频完成可并行，不将未清洗的 token 提前朗读。
2. 独立朗读只使用数据库确认的本用户已保存助手回复。新 RPC 可接收 messageId；为了不破坏现有聊天、历史和跨页消息视图，旧客户端的 text 参数只作为精确查询条件，仍以 RPC 返回的已保存内容为准，不是任意文本授权。查询使用 POST RPC，避免长文本被放进 URL。RPC 为 SECURITY INVOKER，额外限定 auth.uid()、assistant 角色并保留 RLS。试听是独立的 preview 操作，只允许会员白名单音色和服务端固定文本，拒绝同时提交自定义文本。
3. 增加每日语音用量和活动任务租约，覆盖独立朗读、自动朗读、普通转写和课程控制。计量是合成字符数／PCM 实际字节换算向上取整的秒数，不使用客户端 durationMs，不扣答疑代币。旧协议 HTTP 最多两次合成的兼容路径按两次最坏情况预留。失败或取消不自动退还已预留日用量；并发租约在成功、失败和取消后释放，清理失败五分钟到期。既有共享 180 TTS / 600 ASR 每分钟准入不变。
4. 合成 JSON 与普通转写 multipart 在解析前按实际字节有界读取，覆盖未知或虚假 Content-Length，并设置读取截止时间。课程控制保留原有更严格的 8 秒读入上限。
5. 文字模型候选链最多三个物理尝试。权限、账户欠费、免费额度耗尽不继续换模型；明确模型不存在才直接换，适合重试的临时错误先有限退避并遵守 Retry-After。目录发现、准入、等待、候选尝试和响应读取共享总截止时间。所有候选在冷却中时不让每个用户立即重新探测。此截止时间是一次候选链的上限，不是整个含多个 planner 的对话事务总时长。

| 范围 | TTS | ASR |
|---|---:|---:|
| 每账号／北京时间自然日 | 20,000 字符 | 1,800 秒 |
| 全站／北京时间自然日 | 500,000 字符 | 36,000 秒 |
