# 小迪代币计费与用量核算

本文是代币发放、扣费、退款和执行预算的唯一文档来源。核对基线：2026-10-13，`0d322eda40dfdf81c7feb4f37703c9b38bea2b15`；规则已体现在该版本的代码与迁移中，本次未核验生产实例是否执行或真实余额。

## 产品规则

| 项目 | 当前代码规则 |
|---|---|
| 小迪成功请求计费 | 可核验的输入、输出及相关模型调用总计 100 token = 1 代币；同一请求汇总后兑换，不按调用次数分别向上取整 |
| 普通会员月额 | 有效期内每个北京时间自然月 15000 代币 |
| 创始会员月额 | 有效期内每个北京时间自然月 20000 代币；管理员角色本身不授予此档位 |
| 月度余额 | 新自然月刷新，不累积；资格、档位和周期以数据库为准 |
| 已登录用户日赠 | 每个北京时间自然日 300 代币，00:00 刷新，不累积、不需签到；这是初始体验配置，不是已由运营数据验证的最优值 |
| 日赠单轮扣款 | 小迪每轮最多 100，实际消耗少则少扣，余额不足时不超过剩余余额；执行预算内超出扣款的用量记录为平台体验成本 |
| 会员用量来源 | 优先月度钱包；不足时可切换真实日赠余额，同一轮由一个来源结算，不把日赠额累加进月钱包 |
| 其他 AI 功能 | PBL 草稿、点评与辅导继续沿用固定代币价格，共用月度或日赠余额，不由本次文档改价 |

月度钱包仍按实际整轮用量结算，不套用日赠的单轮扣款上限。一枚 token 对应 0.01 代币，钱包沿用 `numeric(18,3)`；旧记录精度保留。固定购买周期定额的旧拟售方案不再作为发放规则；会员有效期与自然月发放是不同概念，开售验收见 [会员交接](../MEMBERSHIP_PAGE_HANDOFF.md)。

客户只看代币余额、有效期和扣除代币，不显示原始 token、换算公式或固定免费对话次数。日赠额不保证任何复杂问题都能完成，也不构成供应商人民币成本封顶。调整常量时必须同步服务端产品常量、数据库权威规则和客户说明，其他文档只链接此处。

## 旧余额与周期

此前已确认既有会员为测试账号，本次规则不追溯补差、不自动补发当月差额、不覆盖旧钱包；新钱包和新周期按新档位发放。同月已有钱包仍保留实际余额。

每日流水按用户与原发放日隔离。跨日结束、取消或退款仅处理原日预留，不加到今日余额。旧输出计费凭证仍按原规则收尾、退款和重放，已结算金额不重算；退款和跨月保护不得因文档整理改变。

## 真实调用的计量范围

`lib/ai/tutor/usage.ts` 为每个已准入请求创建独立 collector，通过显式 observer 接入共享 DashScope 和 helper，不采用跨用户的全局计量状态。

| 调用 | 实现入口 |
|---|---|
| 主回复，含文本/视觉 | `engine.ts`、`lib/ai/dashscope.ts` |
| 资源与页面工具规划 | `resource-search-planner.ts`、`tool-call-planner.ts` |
| Scratch 截图诊断 | `scratch-screenshot-diagnosis.ts` |
| 鸟鸣规划，包括后来未使用的早期调用 | `audio-tags.ts` |
| 用户长期记忆与会话摘要 | `memory.ts` 与摘要出口 |

表中短路径相对于 `lib/ai/tutor/`。纯数据库查询、规则匹配和列表整理不产生模型 token；其他用户或运营任务不计入本请求。

每次真实上游 attempt 独立记录，结束回调幂等。成功请求中已发生且可核验的重试/降级用量计入；整体失败、无有效回复或消息保存失败仍按取消与释放预留处理，供应商可能已产生未向用户收费的成本。

用量可以是合法 `totalTokens`，或完整 `promptTokens + completionTokens`；同时存在必须一致。负数、小数、不安全整数等非法值不参与收费。推理量已包含在输出，既不扣除也不重复加。只有总量时细分字段保留 null；缺失用量不估算收费，其他已核验调用照常结算并记录缺失。

## 摘要与结算时序

最终消息与扣款事务前，等待本轮必要的摘要和鸟鸣规划结束后汇总；结算后不再为本轮启动新文本模型任务。摘要处理此前已保存消息，本轮问答在后续达到阈值时纳入；摘要失败不阻断有效主回复，成功澄清也计入实际工作量。

跨场景记忆维护仍使用现有乐观并发控制，没有由本规则新增跨场景生成锁，不声称已消除重复摘要成本。

## 预留与执行预算

先预留再调用模型。月度钱包整轮上限 `TUTOR_MAX_TOTAL_TOKENS = 131072`，按实际可用余额收缩；主回复输出上限独立为 8192。日赠最多预留本轮扣款上限或实际剩余额，执行预算独立限制为 30000 token。平台补贴不是用户已支付金额。

collector 每次调用前同步预留输入估计量和输出上限，包含并发在途占用。字节、结构开销和图片预留只是执行预算，不是精确分词或收费凭证。可选规划/摘要预算不足时停止相应调用，主回复可缩小输出。截图诊断输出上限 256，用户摘要至多 1800，会话摘要 800。

月钱包无法容纳主回复执行预留时，可在发送主调用前尝试一次 `fallback_tutor_usage_to_free_service`。数据库校验原用户、请求、执行器、凭证、预算不足和真实日赠余额；满足平台日赠执行上限才原子退还钱包预留、关联每日子流水。保留原请求、已有调用和 collector 占用，不重跑；确认切换后才调整预算。取消不重复退还已经返还的钱包预留。

日赠合同必须明确带 `creditUnit='credits'`、`creditPolicy='daily_credits_v1'`、`source='free'`、`dailyChargeCap=100`，预留在 `(0,100]` 且执行预算不超过 30000。月度来源预算不得超过实际预留代币乘以换算率。缺少标记不能解释为任意补贴。

实际用量超预估时阻止后续预算不足调用；数据库扣款不超过原预留，记录差额，不透支余额。这不保证预估等于供应商分词。

## 账单、权限和重放

核心 RPC 为 `reserve_tutor_usage_service`、`begin_tutor_usage_request_service`、`fallback_tutor_usage_to_free_service`、`settle_tutor_usage_service`、`complete_tutor_usage_request_service`；最终两条消息、扣费和终态在同一事务提交。

原始调用与预算保存在 service-role-only 的 `tutor_usage_records`。`free_quota_receipt_id` 可关联每日回退子流水。公共 `TutorBilling` 仅暴露 `source`、`chargedCredits`、`receiptId`；历史重放同样提取这三个字段并保留旧金额，不向客户泄露明细。

请求/凭证幂等、用户锁、20 分钟过期、历史删除和跨月退款保护仍有效。应用重试沿用相同请求/执行器；不确定是否提交成功时，不先退款再重新生成。管理员统计只累加已结算主凭证，不重复累计子流水或预留、取消、过期记录。

## 语音不混入文本代币

ASR 音频和 TTS 字符用量尚未接入这里的代币兑换，不把它们当文本 token 加总。语音协议、实际模型、共享限额、取消和音色只在 [语音协议与验收](voice-31-upgrade.md) 维护；课程明确开启的有限控制另见 [手机搭建](../courses/mobile-building-experience.md)。

旧模型单价及旧预算算例仅代表原记录的模型和日期，不能冒充 Audio 3.1 的当前价格或真实成本。本次未查询供应商最新价格或账单；需要成本结论时另按实际模型、区域和账单核对。
