## 6. 个人页：首屏聚焦「下一步行动」

**状态：暂缓（2026-05-20）**

- **优先级**：低于探索页第二期；探索页第二期已上线，本项待产品确认后排期。
- **阻塞**：需产品确认 KPI（留存 vs 创作）、家长视角首屏、第一期是否仅做方案 A。
- **倾向**：第一期仍建议方案 A（一张动态主卡片），仅移动端；桌面保持现状。

**现状**

- 移动端 `/profile` 聚合：头像与等级、统计、快捷入口、进行中项目、观察、勋章、社区动态等。
- 信息完整，但首屏缺少单一主 CTA，用户需自行判断「现在该做什么」。

**可选方向**

| 方案 | 说明 | 取舍 |
|------|------|------|
| A. 动态主卡片 | 根据状态优先级展示一块：①进行中项目 ②待领取成长任务 ③空状态引导发布/观察 | 需明确优先级规则 |
| B. 折叠次要区块 | 勋章、时间线等默认收起，展开后再看 | 减少滚动，可能降低曝光 |
| C. Tab 分区 | 「继续探索 / 我的创作 / 成就」三分 | 结构清晰，改动面大 |
| D. 桌面/移动差异化 | 桌面保持信息密度，移动只做 A | 两套体验需维护 |

**建议优先级规则（草案，待确认）**

1. 有进行中项目 → 突出「继续项目」+ 最近一条进度
2. 无进行中、有可领取任务 → 突出成长任务
3. 新用户 / 内容为空 → 突出「发布第一个项目」或「记录第一次观察」（已有空状态文案，需上提到首屏）

**讨论问题**

1. 个人页的核心 KPI 是留存（继续项目）还是创作（新发内容）？
2. 家长查看孩子账号时，首屏应偏「进度」还是「成果展示」？
3. 第一期是否只做 A（一张动态卡片），不动整体 Tab 结构？
