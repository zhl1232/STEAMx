# UI GPT Design Prompts

## 文档目的

这份文档用于沉淀本项目各核心页面的 GPT 设计提示词，便于后续在 ChatGPT / GPT-4o 中直接生成页面设计图。

适用场景：

- 让 AI 生成单页高保真设计稿
- 批量生成核心页面视觉方向
- 在新对话中快速同步页面信息架构与设计要求

## 使用说明

- 下列 prompt 已内置统一风格约束，可直接整段复制到 GPT 中使用。
- 默认面向桌面端高保真设计图，同时要求兼顾移动端适配思路。
- 这些 prompt 基于当前项目已有页面结构整理，优先覆盖真实业务页，不含测试页、跳转页和内部工具页。

## 统一设计前提

这些 prompt 默认采用以下设计方向：

- 产品名：`STEAM 探索`
- 产品定位：面向青少年与亲子用户的 STEAM 学习与自然观察平台
- 界面语言：简体中文
- 视觉方向：未来教育平台 + 自然观察频道
- 颜色倾向：明亮背景，蓝绿橙主色
- 风格要求：真实 Figma UI screenshot 风格，轻科技感结合自然感
- 明确避免：海报感、纯插画页、赛博紫、夸张 3D、只有概念没有产品结构
