# 内容质量与验收

> 2026-10-12 整理：汇总既有课程、科学内容核对和发布记录中的有效规则。代码与文档核对基线为 `main@f4eb9e8caee04d79997d9ed4f9401f3f8dcf2510`；本次没有重新执行生产、实物或外部家庭验收。具体模块的权限、审核和发布流程继续以对应维护文档为准。

## 证据与状态

内容完成、技术发布、实物可用和家庭使用分别记录。一次检查只能支持它实际覆盖的结论；以下项目不要求作为所有内容统一串行执行的流程。

| 检查 | 应保留的证据 | 结论边界 |
|---|---|---|
| 文字、材料与步骤核对 | 内容 ID、版本、原始来源、已确认事实和缺项 | 有步骤或材料行不等于内容充分、用户能独立完成 |
| 视频核对 | 同一项目的源视频、哈希、关键动作时间点和核对说明 | 区分画面/字幕事实与编辑补充；未确认的规格、数量和操作参数不补造 |
| 3D 模型确认 | 模型及版本哈希、零件和连接检查、人工确认记录、接受的限制 | 渲染、自动检查和人工模型确认均不能单独证明实物装配稳定 |
| 发布核验 | 应用或资源版本、资产回读、必要的数据库状态及页面检查 | 代码在仓库、CI 通过、资源可读、数据库更新和完整线上验收是不同证据 |
| 实物搭建或实验 | 实际材料/套装及散件、替换件、操作和连接、结果与限制 | 只说明该版本、该材料组合和已验证范围；不自动推广到整套课程 |
| 外部家庭使用 | 体验课程、材料匹配、开始/卡点/完成、再次使用及反馈 | 与作者自测、管理员作品和模拟测试分开，不用展示数量推定需求成立 |

当前事实应带检查日期和证据入口。只有旧记录时注明其日期；没有本轮检查的状态保持待核对。内容变动影响原结论时，按模块规则重新复核，不覆盖旧证据中的日期、数量或哈希。

## 材料与首批体验课程

- 课程材料要求与购买方案分别维护。材料包名称不等于可购买链接，课程/商品的关联也不证明商品组合覆盖所有必需零件。
- 套数核算基于登记的库存、零件映射与替代规则。零必需缺件只表示在这些条件下的核算结果；还需要核对家庭实际持有的零件以及实际连接、支撑和操作。
- 换色、印花替代、结构件替代、可选底板和特殊零件分别说明。不能把默认接受的颜色或面积替代规则写成所有实物搭法都已经验证。
- 首批体验优先从用户已做过实物验证的部分小班课程中选择。具体课时 ID、实际套装/散件、验证日期与范围仍需填写；本次不虚构课程名单或把全部已发布模型标为实搭通过。
- 网站可以向已有匹配材料的家庭提供课程。商城准入与开售条件见商城决策；商城完成不作为网站内容推广前置条件。

材料核算规则与历史粗算入口：[小班](courses/lesson-kit-coverage-small-class.md)、[中班/大班](courses/lesson-kit-coverage-middle-senior.md)。模型状态见 [LDraw 当前状态](ldraw-status.md)，实搭课单与体验任务见 [下一步](next-step.md)。

## 科学内容核对

- 按项目身份和它自己的来源核对材料及操作；不能用同名实验的另一种做法替代原视频。
- 正文区分视频操作、编辑补充的观察/解释/防护措施以及仍未确认的部分。依赖配套组件或说明书的范围要写清；不把未知配比、尺寸、结构或性能写成确定事实。
- 只有“准备材料包、观看视频”的内容，记录为对应准备或观看范围，不将占位步骤描述为完整独立制作教程。已有具体步骤的内容也不能仅凭结构完整就判定已完成内容质量审核。
- 封面优先采用同一项目的真实成品或操作画面。自动取帧仅生成候选，主体、清晰度和场景由人工核对；记录原/新资源和哈希，不以生成图片冒充实拍成果。
- 材料、正文、步骤或课程结构变化后的内容分级复核，遵循 [内容分级维护说明](CONTENT_CLASSIFICATION_IMPLEMENTATION.md)。

### 家庭材料清单补全

`lib/project/content-revisions.data.json` 保存有来源依据的材料/步骤修订，`content-revisions.ts` 在原科学和 LED 内容覆盖之后应用，探索材料分组与正式详情共用同一条读取链。每项绑定 ID、标题、分类、修订前 `sourceHash` 与修订后 `contentHash`；`content-fingerprint.ts` 核对有效描述、完整清单、步骤，以及科学内容的模式、缺项、安全、来源和问答。来源正文变化时保留新正文，旧修订不再套用；不直接写回生产数据库。页面材料、操作步骤与 HowTo 读取同一修订结果。改变动作的步骤不沿用旧索引处的图片；文字保持不变的步骤可保留对应原图。

2026-10-23 对此前 506 项待核对内容逐项对照有效正文：296 项完成实质修订，其中 295 项修改材料、16 项修改步骤（两者有交集）；136 项补齐后纳入材料匹配，160 项虽补了一部分仍有关键缺项，210 项没有足够证据改写。另对原 311 项中的 215、534、548、566、671、701 修正基础分支、漏项或材料规格，使详情与匹配条件一致。纳入匹配仅说明已核对文字条件，不代表实物验证。

- 漏列的清水、纸笔、量具、剪刀、胶棒等，以同一项目已经写明的动作或用量为依据补入；组合材料和替代方案保留各自条件。原套件限制、配方、折剪模板、连接尺寸等未确认时，不凭名称补造，不因补了几件材料就标为可匹配。
- 722「毛毛虫大赛」、806「听话的四角星」、902「猴子翻跟头」按同项目原视频关键帧修订折剪或连接动作；622、751、1081 只补画面确认的材料、数量和准备要求，夹层、闭合或剪线不清楚的部分仍待核对。视频修订记录 `sourceVideo` 的原 URL、SHA-256、实际查看的时间点和证据范围，且只应用于该视频 URL；同 URL 资产替换仍须重新核查。未听音轨、未逐帧看完整视频、未进行实做，不能据演示结果保证任意材料组合都能复现。
- 已核查 27 个项目引用的 143 个步骤图路径，本地资源不存在且公开站点均返回 404，不能把数据库中有 `image_url` 当成已有可用图解。此项为本轮来源核验结果，不以其他示意图替代原项目步骤证据。
- 修订中的准备说明在有效正文完全匹配时显示。`household-projects.data.json` 只收录已完成材料条件核对的项目；仍有缺项的修订可以改善详情，但不会自动出现在「日常材料」分组。822 保留来源说明书依赖，906 保留气球连接与密封动作缺项。

### 两页视频呈现试点

`app/project/[id]/page.tsx` 仍通过 `getProjectById` 读取数据库及既有内容覆盖。`lib/project/video-presentation-pilot.ts` 只在 1301 的 ID、标题、技术分类、原视频 URL 和完整占位步骤匹配时提供本地呈现配置，不写数据库，也不修改原项目对象。若视频或步骤被编辑，退出该覆盖；不能按“只有一步”隐藏其他项目的真实操作。

- [1301 自制电动机](https://steam.bj.cn/project/1301)：制作教程。准备材料在播放器之前，显示画面可辨的材料及规格未核实说明，不统计整包为一种零件。占位步骤及步骤计数改为制作视频，视频时长约 137 秒明确区别于制作耗时。
- 定位点为材料总览 00:03、绕线 00:06、刮漆 00:49、底座 01:20、接线 01:34、试转 02:04。提醒保留“一头半刮、一头完全刮干净”和“木块孔朝上”。定位保留播放/暂停状态，元数据未就绪时只保留最后一次选择；播放结束不调用完成接口。
- [892 逃出手心](https://steam.bj.cn/project/892)：继续使用数据库中的视频和四个动作，保留 10—16 秒、16—24 秒、失败复位及不勒手指/不硬拽提示，不覆盖正文。
- 来源核对：2026-10-21 公开页面确认视频路径分别为 `kejiao16a/六年级/013_自制电动机/video_1.mp4` 与 `jichu-haohua/069_252.逃出手心/video_1.mp4`。1301 时间点和材料依据本次提供的全片每秒一帧及烧录中文字幕核对；未听音轨、未实做，不推断尺寸、线径、电池规格或供应情况。

`playwright.project-video-pilot.config.ts` 使用本地只读 HTTP 数据夹具运行真实 Next 页面，串行检查手机/桌面布局、时间点、暂停/继续、元数据等待、892 与非目标项目。视频是 140 秒灰色视频夹具，用于验证浏览器媒体行为；不代表原片内容核对、生产账号、真实完成记录写入或实物验收。原收藏、作品、评论、历史记录、访问权限与材料商品入口契约保持不变。该试点不新增分类、迁移、商品或生产发布日期。
