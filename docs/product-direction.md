# 产品方向与当前约束

> 当前方向基线。本文提炼历史评审中仍有效的产品原则，并结合 2026-09-26 的商城渠道决策更新。历史评审和线上数据是时间点记录，不是实时运营数据；实现状态以代码、迁移和当前审计为准。

## 当前主线

平台当前优先验证一条可完成、可反馈、可留下成果的首次成功路径：

`挑一节积木课 → 按 3D 步骤完成 → 拍照上传 → 获得反馈`

核心观测指标是注册后 7 天内产出第一件作品的人数。新增入口、内容和功能应先说明它如何帮助用户完成这条路径，或如何提供可靠的观测信号；没有明确关系的能力保持后置。

产品体验应把真实作品放在互动指标和功能数量之前：优先让用户完成一个可展示的作品，再引导评论、排行榜、徽章或其它扩展行为。课程、项目、挑战和自然观察产生的成果统一进入作品视图，过程材料作为记录保留。

## 当前有效约束

- 免费课程保持公开可用，课程流程不设置付费墙；会员能力只能补充工具、答疑或 AI 配额，不能阻断首次成功路径。
- 面向儿童的界面不使用倒计时、限时优惠、名额告急等逼单表达，也不在孩子的学习流程中推动购买。
- 主线内容应给出清晰任务、完成标准和可选支撑，同时保留用户设计、测试和迭代的空间；挑战不能退化成固定答案的教程。
- 互动安全资格、会员、角色和成长奖励各自独立。公开阅读与保存进度的门槛不能被会员绕过，互动写入必须服从当前安全规则。
- 自动化互动不得伪装成人与儿童对话。任何冷启动信号都不能被当作真实用户需求或作品质量的替代证据。
- 家长价值应通过可保存的作品、课程完成反馈、材料清单和清晰的学习进展体现；这些能力必须服务于学习闭环，不能抢占孩子的主任务。

## 商城与实物履约边界

当前准备站内交易、人工采购和供应商代发，直接对接支付宝与微信支付；已具备公司执照和企业支付宝，支付产品审核尚未完成。公开实物购买入口、淘宝跳转和新建订单默认关闭，历史订单与售后保留。代码准备不代表真实支付已开通，交易状态只能由验签后的渠道结果确认。

后续开放时，商品按课程、课时和项目关联；购买始终不是课程完成条件。首期单规格订单、固定运费、有限库存、人工采购、单包裹物流和整单退款，不启用 1688 自动下单。管理员测试结算仅限本地隔离环境；生产开放需完成商户审核、迁移、配置及真实小额闭环验收。
