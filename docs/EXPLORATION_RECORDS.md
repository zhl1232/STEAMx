# 探索记录发布流程

探索记录以文字为主，允许只写文字或只添加图片；两者不能同时为空。最终作品仍要求图片。点击“发布记录”才提交审核，恢复本地文字不会自动提交。

项目完成记录接口与通用Journey的项目记录入口均使用公开审核契约，不提供私密保存模式。未提交文字仅在当前标签页按账号、项目恢复；切换账号、退出登录或发布成功清理，发布失败保留。照片、视频文件不持久化恢复。

记录状态依次为明确提交、待审、通过后公开。初次发布和重新发布不会提前填写published_at；公开列表和计数仍要求is_public=true、status=approved、moderation_state=approved。撤回分享退回未公开，重新发布再次审核。

底层private/draft字段保留给撤回状态及PBL阶段草稿，不新增数据库结构、不变更RLS、不批量迁移既有记录。

开始探索防重复点击，失败显示重试提示；记录列表/详情读取错误与空列表分开，失败保留已有内容并允许重试。发布提示按服务端返回状态显示，异常draft响应不能视为发布成功。

隔离验证覆盖文本/图片/空白校验、重复提交、失败恢复、账号切换与退出清理、旧上传结果失效、审核状态、公开计数过滤和撤回再审核。测试使用mock边界，不代表真实数据库、Storage或审核服务的端到端验收。
