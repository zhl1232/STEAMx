# LDraw 模型逐课验收记录（归档）

本文件从 `PROJECT_INDEX.md` 第 8 节移出。这里记录的是**已完成模型的一次性重建与验收细节**：对照哪份搭建说明 PDF、每步新增件数、零件号修正、验证等级（多数为 `renderer-verified only`，未在 BrickLink Studio 打开）。模型定稿后这些结论不再变化，日常开发不需要读。

什么时候回来查这里：要**修某个具体模型**、**补新模型**，或要弄清某个零件号当初为什么这么选。

仍留在 `PROJECT_INDEX.md` 第 8 节的是不会过期的部分：发布门槛、`ldraw-models/` 目录约定、打包管线。可复用的重建流程与坐标/缺件/厚度约定在 `.agents/skills/image-to-ldraw/references/`。

哪些课时有 3D 模型不在本文件维护：看 `public/courses/ldraw/*.mpd`，或课时 `content.building3d.ldrawModelUrl`；运行时由 `lib/courses/building-lesson-flow.ts` 的 `hasRealModel()` 判定。
