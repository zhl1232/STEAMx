库存：9090-2 × 1 + 9076-1 × 1 + 45002-1 × 1。每课独立使用完整库存；默认接受换色/印花替代。51262（8×8 薄板，含 System 替身 41539）同号同色出现在 stepIndex > 0 的步骤时按结构件计入必需缺件；仅用于第 0 步时仍为可选。普通分配后，必需的 51262 缺口可用剩余 4672（4×8，32 凸点）和 6490（8×16，128 凸点）按每块 64 凸点覆盖；先同色，再按换色偏好用其它颜色，每轮先 4×8 后 8×16，整块消耗且多余面积不复用，不使用 44524（2×8）。覆盖部分进入替代清单，不计入必需缺件。4268（24×24 底板，含替身 3811）保持可选，不计入必需缺件；手动结构底板白名单为空。人物散件折算为完整小人后与套装小人抵扣。

- 模型：55 课
