# 中班 / 大班套装对比粗算

## 材料显示名称与语料回归

材料名称由 `lib/utils/ldraw-bom.ts` 根据 LDraw 零件 ID 和模型内描述生成。已确认的螺丝位置/相位变体使用同一实体积木名称；课程专用近似件仅对已核对的 ID 命名，不按任意后缀推断。无法识别的零件仍保留原描述，中文覆盖检查会继续报出缺项。LDraw `61898b` / `61898bc01` 按模型中的塑料片螺旋桨及成形状态命名，不能套用其它零件目录同号的印花圆盘名称。

人物散件按成人、儿童分别折算：同类基础部件跨颜色和印花合计，手臂每两只折一人，各部件需求取最大值后将成人与儿童需求相加。展示层已合并的“完整小人”直接抵扣完整小人库存，不再次生成需求；服装颜色不影响抵扣，也不进入换色清单。现有完整小人零件与折算行共用库存，不重复消耗。全课与分步显示口径见 [手机搭建](mobile-building-experience.md#使用场景与界面)。

语料回归覆盖现有 220 个正式 MPD（小班 100、中班 79、大班 41），并核对 2026-10-20 新增 60 个模型的发布清单、人工确认哈希、分步依赖和 BOM。此数量是材料显示测试范围；下文库存粗算仍是原来 55/5 课的快照，不代表新增模型已重新完成库存或实物核算。

## 中班（课程 6）

库存：9090-2 × 1 + 9076-1 × 1 + 45002-1 × 1。每课独立使用完整库存；默认接受换色/印花替代。51262（8×8 薄板，含 System 替身 41539）同号同色出现在 stepIndex > 0 的步骤时按结构件计入必需缺件；仅用于第 0 步时仍为可选。普通分配后，必需的 51262 缺口可用剩余 4672（4×8，32 凸点）和 6490（8×16，128 凸点）按每块 64 凸点覆盖；先同色，再按换色偏好用其它颜色，每轮先 4×8 后 8×16，整块消耗且多余面积不复用，不使用 44524（2×8）。覆盖部分进入替代清单，不计入必需缺件。4268（24×24 底板，含替身 3811）保持可选，不计入必需缺件；手动结构底板白名单为空。同中文色名按同色核算；Toolo / Duplo Technic 示意配色以套装实配颜色为准，同款同色不计替代，真实图案差异单独说明。人物散件折算为完整小人后与套装小人抵扣。

- 模型：55 课
- requiredMissing=0：11 课
- 同时没有未知零件：11 课
- 仍未知的零件种类：0
