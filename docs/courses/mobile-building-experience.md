## 使用场景与界面

此前带课观察是孩子常按“想做什么作品”选课，家长陪搭时频繁操作手机。它不是外部家庭的规模化验证。保留孩子自由选课、搭完玩耍和反复尝试，不强制分享、上传或立即选下一课。

`course-lesson-catalog.tsx` 在达到原目录阈值且全为 building_3d 的课程中，手机显示两列成品卡，桌面沿用原列数；普通课程不改为此模式。单套课时链接、已有成品图数据与懒加载保留，图片缺失/失败时仍能按标题进入课时，不新增逐课查询。

工作区手机竖屏优先模型和本步零件，两列小图显示名称与数量，复用 `PartThumbnail`；缺图用颜色占位，图片颜色不符仍显示真实颜色提示。全课清单默认收起，长零件列表可独立滚动，横向全屏沿用材料侧栏。材料核算限制和实搭证据见 [小班覆盖](lesson-kit-coverage-small-class.md)、[中大班覆盖](lesson-kit-coverage-middle-senior.md) 和 [内容质量](../content-quality.md)，不把无缺件视为保证搭成。

`ldraw-step-highlight.ts` 只降低已完成步骤原生边线透明度，保留本步原边线；不改变面色、线色、几何、BOM、条件线视角判断或绘制批次。已完成边线透明度为原来的 25%，回看、空步、目标未加载或释放时恢复相应材质；迟到加载服从当前步骤。该提示不等于自动展示连接点，被遮挡处仍需手动旋转。

连续 3D 搭建页使用同一个 `buildBuildingLessonFlow` 页序，保留相机和整页位置；跨入/离开课件或视频回到页首，零件区切步回到顶部。普通翻步不重置相机，首次初始化和主动视角按钮仍按原行为。模型首次加载期间也接受步骤改变，不让迟到模型改回旧步。

## 语音搭建的产品边界

入口文案保持“会员权益 · 目前免费体验”。当前通过登录与课程访问校验即可体验，不要求先购买、不扣答疑代币；尚无确定的免费体验结束日期，不自动转付费。结束体验需另行落实服务端会员授权和说明。

只在用户主动开启后请求麦克风权限并监听；进入页面、返回课程或答疑结束均不自动开启。明确协议为：

| 口令 | 动作 |
|---|---|
| 小迪，下一步／下一页 | 前进一个课程展示页 |
| 小迪，上一步／上一页 | 返回一个课程展示页 |
| 小迪，暂停 | 停止麦克风和当前请求，恢复需点击继续 |
| 小迪，退出 | 关闭本模式 |

严格整句匹配可接受有限标点、空格和礼貌词；问句、否定、引述、多个命令、长闲聊、近音前缀或单独“下一步”不执行，返回 `command: null`，不自动转答疑。这是 [AI 规范](../AI_DEVELOPMENT_GUIDELINES.md) 规定的有限协议例外，不能推广为普通聊天的关键词门控。

控件经 `buildingVoiceControlsSlot` 放入工作区全屏容器，原生和 CSS 全屏均保留暂停/退出。切到作品视图卸载并停止，返回后重新明确开启。

## 页序、时效与上下文

语音、按钮、目录、URL 和 `course.focus_lesson_step` 共用 `handleStepChange`，按课件、视频和 3D 展示页序导航，不直接增减模型内部步号。小迪课程上下文也复用展示页序；只有标题和文本，不含已读图像、视频或连接几何，不能宣称已看见具体颜色或连接位置。

请求绑定用户、课程、课时、展示页版本、导航 epoch 和请求身份。手动 A→B→A、切课、换账号、返回或取消后，迟到结果不能再翻页；导航函数同步校验 epoch，覆盖 React 尚未提交的间隙。首尾边界只提示，不越界。

## 采集与生命周期

本地声音强弱与停顿切段保留约 300ms 开头，约 650ms 安静结束一段，每段最多 8 秒。等待识别时不接新段；命令成功用本地提示音反馈再监听，不调用云端播报。持续声音到达截断上限后需重新安静，避免不停上传同一段长声音。

本地切段不是本地唤醒或离线识别；未先在设备上识别“小迪”。教学讲话、电视、人声和误触发也可能上传 ASR 并消耗识别成本。界面提示先停顿再说，实际漏听和噪声表现仍需真机验证。

暂停、退出、后台、麦克风中断、换账号/课时、媒体播放或打开小迪答疑时停止并释放采集。回前台、视频结束不自动恢复。网络错误、超时、无效响应和 429 停止自动识别，需手动重启。课程控制与小迪录音/朗读在同一页面互斥，不跨设备或标签页控制。

取消信号已从课程端点传入 `transcribeTutorSpeechPcm16`；不再写“不接受取消信号”。具体 task/legacy 传递及聊天单独停止朗读的差别见 [语音协议](../ai/voice-31-upgrade.md)。迟到结果不执行，已产生的供应商费用仍不能保证撤销。

## 课程端点的独立限制

`POST /api/tutor/speech/course-control` 接收 audio、durationMs、courseId、lessonId，仅返回 command。服务端先认证和查询课时，要求课程 approved、符合当前内容分级门禁、课时属于课程且为有展示页的 building_3d；原有已批准但未上架历史课直达权限保留。

| 规则 | 当前课程控制契约 |
|---|---|
| 音频 | 16kHz 单声道 PCM16，按实际字节最多 256000 字节/8 秒，不信任客户端时长 |
| 每用户分钟窗口 | 最多 20 段／固定 60 秒 |
| 每用户日窗口 | 最多 120 段／固定 UTC 日；上海时间 08:00 重置 |
| 429 | 区分窗口，返回 retryAfterSeconds、resetAt、Retry-After，保留按钮翻页 |

这是课程控制的识别准入，不是客户代币余额，也不覆盖普通语音聊天的全部限制。新语音层另有共享预算，两层均须通过；共享数值只在语音文档维护。

端点为已准入识别记独立 `course_voice_recognition` 元数据：用户/课程/课时 ID、字节、按字节推导时长、命令类别、结果、配置模型与耗时。不保存录音或转写全文，不回传转写，不写聊天、代币或内容记录；这些是工作量记录，不是供应商已扣款凭证。

## 验收要求

目录、零件、页序、相机和材质回归与语音回归分开。历史合成声音、替身 Auth/ASR、单隔离 PGlite 的结果不等于真实麦克风、识别准确率、多连接生产预算或实搭通过，也不能重复累加旧测试数。

真实验收仍须记录：手机权限及后台/来电、全屏操作与释放；不同说话者、距离和噪声的准确率/延迟；长声音截断后的恢复；连续陪搭的触屏、误翻、重复翻页和旋转次数；实际上传时长与供应商账单。来源、版本和环境写清楚。

本次不实现持续开放式语音对话、本地唤醒、离线识别或多设备共享监听。当前任务统一见 [下一步](../next-step.md)，不另建一份相互竞争的发布待办。
