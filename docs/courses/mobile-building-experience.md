# 手机积木搭建体验与小迪语音控制

更新：2026-10-12。本文区分用户观察、本次实现与后续方案；实现和测试通过不代表生产已发布。

## 使用场景与已确认约束

项目负责人观察到：孩子很大程度上按“想做什么作品”选课；成品可以玩时，会继续玩一会儿。带孩子搭建的人还要频繁操作手机，是当前明显的体验负担。这些是现有带课观察，尚不能当作外部目标家庭的规模化验证。

本轮确认：

- 手机课程目录需要显示作品成品图，让孩子和家长知道将要搭出什么。
- 连续切换 3D 搭建步骤时，保留家长已经调好的观察角度；不要强制旋转、套用新的关键视角或加入视角过渡动画。
- 尽量在同一屏看清模型、本步零件形状和数量，以及新增结构所在位置。提示保留积木原色，便于与手中材料对应。
- 搭完后的自由玩耍属于当前使用过程；本轮不增加强制分享、上传或立即进入下一课的步骤。

## 本次界面实现

### 成品选课

`course-lesson-catalog.tsx` 的既有成品卡模式在手机也显示两列图片卡；桌面延续 2/3/4 列。只渲染一套课时链接，避免同一课时产生隐藏的重复入口。该模式沿用课程详情页原有条件：课时达到目录阈值且全部属于 `building_3d`；普通课程列表和按阶段学习的课程不受影响。

图片继续使用已有 `finished_image_url → finishedImageUrl` 数据与懒加载，不增加逐课查询。图片完整包含在 4:3 区域内，缺失或加载失败时保留标题、状态和进入课时的链接。

### 搭建中的模型与材料

`building-3d-workspace.tsx` 在手机竖屏适当收紧画布与说明区域，本步零件使用两列小图、名称和数量。复用已有 `PartThumbnail` 与本地零件图；没有对应图片时使用颜色占位，图片不是目标颜色时沿用真实颜色标记。手机默认收起全课清单，优先显示本步材料；长清单在零件区内滚动。横向全屏沿用右侧单列材料区。

`lib/utils/ldraw-step-highlight.ts` 保留本步真实 LDraw 模型的原生边线，将已完成步骤的边线透明度降到原来的 25%，通过轮廓清晰度区分新旧结构。仅缓存并替换已有步骤的线材质，不修改线条颜色、积木面色、模型几何、零件清单或原有绘制批次；条件线保留原 shader 的视角显隐和深度测试，淡化线不写入深度。回看旧步会恢复该步的原线材质；进入空步、目标尚未加载或释放场景时恢复全部原线材质。迟到加载只服从当前选中步骤，模型之后的收尾页不会把最后一批零件继续标成新增。

初次浏览器检查发现统一橙色边线会把大板的密集凸点染成一整片橙色，影响按原色找零件，因此采用上述明暗方案，大板原有边线颜色规则也随之保留。

这项提示帮助识别新增结构，尚不等同于自动标出每个连接点；被遮挡的位置仍需家长按原有方式旋转查看。此次没有加入自动选视角、连接动画或透视显示。高亮改动针对真实 LDraw 分步模型，其他模型格式沿用原有展示逻辑。

### 连续翻步

普通 `focusStep()` 不触发相机重置；原有首次初始化和用户主动点击“视角”按钮的行为保留。首次模型加载等待期间也接收步骤变化，避免模型最后停在旧步骤。

`lesson-page-client.tsx` 复用 `buildBuildingLessonFlow` 判断当前页和目标页的种类：两页均为 `build` 时保留整页滚动位置；跨入或离开课件、视频时沿用原来的回到页首行为。零件区自己的滚动在切步时回到开头。课程 URL 中的页码、目录跳转与小迪工具仍使用同一个步骤导航入口。

## 本次有限语音控制实现

2026-10-12 已按确认范围加入课程内明确开启的“语音搭建”，尚未生产发布，也未完成真实手机、供应商识别或家庭搭建验收。目标是家长把手机放好后连续陪搭，按口令翻页或回看；本批没有加入持续开放式语音对话。

### 开启与操作

产品权益与体验方式已确认：**会员权益 · 目前免费体验**。语音控制定位为会员权益，现阶段开放免费体验；入口先明确会员权益归属。当前通过登录及课程访问校验即可体验，不要求先购买会员，不扣答疑代币。免费体验仍受下述识别上限约束。尚未指定结束日期；本批不增加自动转付费或扣款，结束免费体验时再落实服务端会员授权与相应界面说明。

已登录用户在积木课点击“开启”，授权麦克风后进入监听；不会因为进入课程、返回页面或收到上一条回答就自动开启。明确口令按下表执行：

| 口令 | 操作 |
|---|---|
| “小迪，下一步”／“小迪，下一页” | 前进一个课程展示页 |
| “小迪，上一步”／“小迪，上一页” | 返回一个课程展示页 |
| “小迪，暂停” | 停止麦克风与当前请求，恢复需要点击“继续” |
| “小迪，退出” | 关闭本模式 |

课程页通过 `LessonWorkspaceRenderer` 的 `buildingVoiceControlsSlot` 将语音条传入 `Building3DWorkspace`，放在工作区的全屏容器内。浏览器原生全屏及 CSS 横屏全屏中仍能点击暂停、退出；切换到“作品”视图会卸载控件并停止收音，返回课程后需要重新明确开启。

`lib/courses/building-voice-commands.ts` 对识别结果做严格整句匹配，允许有限标点、空格及“请／请你／麻烦你／谢谢”等礼貌词。问句、否定、引述、多个命令、长闲聊及“小弟”等近音前缀不执行；只含“下一步”也不会翻页。这是明确开启的课程控制协议，不以正则替代开放式答疑的语义判断。没有匹配时响应 `command: null`，不会自动转入小迪答疑。

普通小迪仍保留长按录音、松手转写后发送，以及面板转写填入输入框的既有入口。普通语音聊天和朗读沿用原有权限与计费规则，不套用本控制端点的次数限制。它们的入口仍为 `use-tutor-voice.ts`、`app/api/tutor/speech/transcribe/route.ts` 与 `lib/ai/tutor/speech.ts`；回复朗读结束不会因此变成持续开放式对话。

### 与页面、小迪上下文使用同一顺序

语音导航与按钮、目录、URL 和 `course.focus_lesson_step` 工具共同调用 `handleStepChange`，使用 `buildBuildingLessonFlow` 的课件、视频、3D 搭建展示页序，不直接加减模型内部步号。连续 3D 搭建页沿用已有相机和滚动位置，前后回看不会强制更换观察角度。

服务端 `lib/ai/tutor/context-builders.ts` 的 `buildCourseContext` 同步复用 `buildBuildingLessonDisplaySteps`，纠正原来读取旧 `course_lessons.steps` 导致同一个页码内容不同的问题。课程上下文只包括页面标题和文字说明，未读取课件图像、视频画面或模型连接几何；小迪不能仅凭这份文本宣称已看到具体颜色、数量或连接位置。Scratch 的步骤/子动作语义及原有科学上下文保持各自范围。

每次导航都有递增的 epoch；请求同时绑定用户、课程、课时、展示页版本和请求身份。手动 A→B→A、浏览器回退、切课时或账号后，旧识别结果不能重新翻页；页面导航函数还会同步检查 epoch，覆盖 React 尚未提交页面状态的间隙。

### 声音采集与监听生命周期

`building-voice-capture.ts` 在当前页面维持一个明确授权的麦克风会话，使用本地声音强弱与停顿切段：保留约 300ms 开头，约 650ms 安静后结束一段，每段最多 8 秒。识别等待期间暂停接收新段；命令成功后显示简短反馈并播放本地提示音，再恢复监听，不调用云端朗读。持续噪声或独白达到 8 秒截断后，需要重新安静才接收下一段，避免同一段连续声音不断上传。

监听提示要求“先停顿一下，再说口令”，减少长声音截断后立即开口被忽略的困惑；是否足以让家长理解，仍需要在实际手机和课堂背景声下验证。

**本地切段不是本地唤醒或离线识别。** 当前没有在手机上先识别“小迪”；有足够声音且形成一段后仍需上传 ASR。闲聊、对孩子讲解、电视人声或误触发也可能产生识别费用。长闲聊如果有正常停顿，仍可能逐段上传，最终由服务端次数上限约束，不能描述成“不是口令就没有成本”。

`use-building-voice-controls.ts` 维护开启、监听、处理中、反馈、暂停、退出和错误状态。暂停、退出、切课时/账号、页面进入后台、麦克风中断会取消当前前端请求并释放采集资源；回到前台不自动恢复。第一/最后一页只给到达边界的提示，不多翻页。网络错误、超时、无效响应和 429 都停止自动识别，需用户再次点击。

`building-voice-controls.tsx` 在打开小迪答疑或播放本课媒体时暂停本模式；再次开启会暂停本课正在播放的媒体并收起答疑。`tutor-audio-session.ts` 协调同一页面的搭建控制与小迪录音/朗读所有权，避免两者同时使用麦克风或把朗读内容再次识别为口令。该机制不控制另一浏览器标签页或另一设备。

取消可阻止尚未发起的供应商请求，并丢弃迟到结果。现有 `transcribeTutorSpeechPcm16` 不接受取消信号；已经开始的云端识别不能保证因用户退出、前端 20 秒超时或切后台而撤销费用。服务端识别超时仍沿用原有实现，禁止自动重试。

## 识别费用、限额与记录

### 只限课程语音控制的服务端规则

`POST /api/tutor/speech/course-control` 接收 `{ audio, durationMs, courseId, lessonId }`，只返回 `{ command }`。端点先认证并复用 `getLessonInCourse`，要求课程 approved、满足当前内容分级门禁、课时属于该课程且为有展示页的 `building_3d`；保留已批准但未上架历史课的直达权限。

| 规则 | 当前实现 |
|---|---|
| 每段长度 | 16kHz、单声道 PCM16，按实际字节计算最多 256,000 字节，即 8 秒；不信任客户端声明时长 |
| 分钟窗口 | 每个已登录用户最多 20 段／固定 60 秒窗口 |
| 日窗口 | 每个已登录用户最多 120 段／固定 UTC 日窗口；上海时间每天 08:00 重置 |
| 准入时机 | 两个数据库窗口均通过后才调用 ASR；识别失败或未命中也计次数，不自动退款或重试 |
| 用户代币 | 本控制端点不进入聊天、LLM planner 或 AI 代币 RPC，不扣小迪答疑代币 |

沿用数据库 `consume_rate_limit` 的原子计数、`auth.uid()` 归属及无客户端写入策略的 RLS。端点 key、限额和窗口固定在服务端；用户修改请求字段或另外调用 RPC 不能减少/重置本端点的固定窗口计数。限流服务不可用时阻止识别，不降级为无限调用。日窗口不是任意滚动 24 小时，跨窗口边界会重新可用；此限制也不代表全站、多账号或所有供应商调用的总成本上限。

429 响应区分分钟和日窗口，附带 `retryAfterSeconds`、`resetAt` 与 `Retry-After`，界面显示何时可重新开启，并保留按钮翻页。这套次数只是平台识别保护，不是客户代币余额。

### 内部成本估算

按 2026-10-12 核对的[阿里云官方模型说明](https://help.aliyun.com/zh/model-studio/qwen3-asr-flash-realtime)，默认 `qwen3-asr-flash-realtime` 在华北 2（北京）的公开原价为 **0.00033 元／输入音频秒**。以下仅为该模型/区域的音频输入估算，没有真实用户账单：

| 算例 | 输入时长 | 按公开秒价估算 |
|---|---:|---:|
| 一条 2 秒口令 | 2 秒 | 0.00066 元 |
| 30 条、每条 2 秒 | 60 秒 | 0.0198 元 |
| 一个固定日窗口 120 段，每段都到 8 秒 | 960 秒 | 0.3168 元，约 0.32 元 |

实际账单按供应商记录和当前模型/区域定价核对；环境变量可更换模型，优惠及计费规则也可能变化。上述数字不含其它语音聊天、开放式答疑、网络、服务器等服务成本，不是全站或任意配置下的人民币硬封顶。执行命令没有调用答疑模型，ASR 本身仍为联网模型服务。

### 成本元数据与隐私

端点对已准入的识别输出独立结构化 `course_voice_recognition` 日志：用户/课程/课时 ID、实际 `audioBytes`、按字节推导的 `durationMs`、命令类别、成功/未命中/失败、配置模型和耗时。日志不含录音、转写全文、供应商原始响应或异常原文；接口不返回转写文本，也不把控制语音写入聊天、代币流水或内容记录。

这些字段帮助估算提交识别的输入工作量，不是供应商确认扣款。当前通用 `logger.info` 不输出生产普通事件，所以该端点单独写服务端结构化日志，没有修改全局日志规则。

2026-10-12 手机 UI 批次的历史结果：7 个相关测试文件、75 项测试通过；该批模块及依赖的 TypeScript 检查和 `git diff --check` 通过。浏览器检查覆盖 390px / 320px 目录、390×844 与 320×568 搭建页、844×390 横向全屏和 1440×1000 桌面，未出现横向溢出；检查了原面材质、旋转后前后翻步、旧边线淡化及首步慢加载中的快速前后翻页。320×568 仍可能需要先滚到搭建区，连续翻步保持已找到的位置。浏览器夹具复用真实课程组件、全局样式和模型，路由、鉴权及 API 使用隔离替身；未写入生产数据。这些是语音实现前的界面证据，不作为完整语音验收结果。

本轮定向回归共 17 个测试文件、242 项通过，覆盖声音切段、持续噪声、麦克风权限与资源释放、音频互斥、单个在途请求、用户/课时变化、A→B→A、超时/取消后的迟到响应、首尾页、限流提示、页面与小迪同一展示页序，以及全屏保留控件、作品视图卸载。该数量已包含端点与严格命令解析的 58 项及本轮相关 UI 回归，不再累加历史 75 项。当前检出的模块与依赖范围 TypeScript、改动代码的 Oxlint 和差异空白检查通过，完整仓库检查以远端 CI 为准。

真实既有限流 SQL 在隔离 PGlite 的 152 个断言通过，覆盖 20/120 窗口、参数变化不能重置、RLS 与用户隔离。PGlite 是单隔离数据库检查，API 并发用例使用模拟原子准入，均不替代多连接生产 PostgreSQL 并发测试。

语音浏览器验收使用真实课程页面、工作区、hook、声音切段、Web Audio 采音/重采样和仓库模型；物理麦克风替换成本地合成声音，登录、课程数据及 ASR 服务使用隔离替身。320×568、390×844、1440×1000 的开启、监听、处理、反馈、暂停与长限流文案均无横向溢出，主要语音按钮至少 44px。静音不发识别请求，无关指令不自动进入答疑；暂停、退出、打开小迪或播放本课视频会停止采音，视频结束不自动恢复。旋转后前后翻页保留相机；手动 A→B→A、暂停或作品切换后的迟到响应不再导航。原生全屏与 CSS 回退均验证竖屏/844×390 横屏的暂停、退出可点，切作品卸载采音、回课程需要重新开启。隔离浏览器记录未出现外部请求、聊天/代币请求或 JavaScript 错误；这些结果不测量真实 ASR 准确率或账单。

发布前的实际手机与家庭验收仍需检查：

- 真实麦克风权限、浏览器后台/来电/工具栏变化、横屏全屏，以及关闭后麦克风是否释放。
- 普通话、孩子/家长声音、不同距离及背景声下的识别准确率和端到端延迟；本地测试不代表供应商真实识别表现。
- 连续长声音被截断后的重新准备提示：安静约 650ms 才接收下一段；在界面显示监听后立即说口令是否容易漏听。
- 连续陪搭时实际触碰手机次数、误翻/重复翻页、仍需旋转模型或找材料的次数。小图与边线提示不能证明实体零件连接可行，也不能代替实搭验收。
- 与公开秒价估算对照实际上传段数、音频时长及供应商账单，检查日窗口限额是否适合真实课程长度。

完整可打断的语音答疑、本地唤醒词、离线语音识别和多设备共享监听均未在本批实现。代码、自动测试和浏览器夹具通过，不等于真机麦克风、实体搭建或生产发布已完成。
