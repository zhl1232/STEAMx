# 手机积木搭建与有限语音控制

本文维护选课、模型与材料展示、翻步和课程内有限口令体验。核对基线：2026-10-13，`0d322eda40dfdf81c7feb4f37703c9b38bea2b15`。代码存在和历史夹具测试不代表本次生产、供应商或真实家庭验收。

语音模型、配置、共享预算、缓存和取消传递只在 [语音协议](../ai/voice-31-upgrade.md) 维护；计费只在 [代币规则](../ai/tutor-credit-accounting.md) 维护。

## 使用场景与界面

此前带课观察是孩子常按“想做什么作品”选课，家长陪搭时频繁操作手机。它不是外部家庭的规模化验证。保留孩子自由选课、搭完玩耍和反复尝试，不强制分享、上传或立即选下一课。

`course-lesson-catalog.tsx` 在达到原目录阈值且全为 building_3d 的课程中，手机显示两列成品卡，桌面沿用原列数；普通课程不改为此模式。单套课时链接、已有成品图数据与懒加载保留，图片缺失/失败时仍能按标题进入课时，不新增逐课查询。

工作区手机竖屏优先模型和本步零件，两列小图显示名称与数量，复用 `PartThumbnail`；缺图用颜色占位，图片颜色不符仍显示真实颜色提示。全课清单默认收起，长零件列表可独立滚动，横向全屏沿用材料侧栏。材料核算限制和实搭证据见 [小班覆盖](lesson-kit-coverage-small-class.md)、[中大班覆盖](lesson-kit-coverage-middle-senior.md) 和 [内容质量](../content-quality.md)，不把无缺件视为保证搭成。

`ldraw-step-highlight.ts` 在切步或当前步模型到达时，仅让该步新增件的原生边线以珊瑚红轻柔亮起淡下一次（1.2 秒）；深红/红色零件改用浅暖色提高对比，随后保留本步原边线、降低已完成步骤原生边线透明度；不改变面色、静态线色、几何、BOM、条件线视角判断或绘制批次。已完成边线透明度为原来的 25%，回看、空步、目标未加载或释放时恢复相应材质；迟到加载服从当前步骤。动态颜色在原生线色与强调色之间平滑过渡，结束恢复原线色；单层原生边线不加粗、不增加绘制批次。描边始终启用深度检测，不穿透遮挡。回看和跳步只强调目标步，连续切步立即取消旧动效，空步不强调任何旧件。系统减少动态效果时直接显示静态区分；偏好变更、后台、模型切换和卸载会结束动效。场景按需渲染，仅在动效、旋转阻尼、模型到达或尺寸变化时请求帧，静止后停止。该提示不等于自动展示连接点，被遮挡处仍需手动旋转。

连续 3D 搭建页使用同一个 `buildBuildingLessonFlow` 页序，保留相机和整页位置；跨入/离开课件或视频回到页首，零件区切步回到顶部。普通翻步不重置相机，首次初始化和主动视角按钮仍按原行为。模型首次加载期间也接受步骤改变，不让迟到模型改回旧步。

## 语音搭建的产品边界

入口文案保持“会员权益 · 目前免费体验”。当前通过登录与课程访问校验即可体验，不要求先购买、不扣答疑代币；尚无确定的免费体验结束日期，不自动转付费。结束体验需另行落实服务端会员授权和说明。

只在用户主动开启后请求麦克风权限并监听；进入页面、返回课程或答疑结束均不自动开启。明确协议为：

| 口令 | 动作 |
|---|---|
| 小迪，下一步／下一页 | 前进一个课程展示页 |
| 小迪，上一步／上一页 | 返回一个课程展示页 |
| 小迪，暂停 | 停止麦克风和当前请求，恢复需点击继续 |
| 小迪，退出 | 关闭本模式 |

采用 sherpa-onnx 中文端侧 KWS 检测六条“完整唤醒名 + 动作”组合，不再上传普通说话。只提供表中功能，不开放听写/问答。暂停关闭麦克风，继续必须点击；退出仅关闭语音模式，不退出课程、不丢弃作品。按钮仍随全屏工作区显示。

**KWS 不等于全文语义识别。** 不接受可选礼貌词，不把一个“下一步”当命令。声音前需约 660ms 安静，再说完整口令；最多 5 秒音频，句末约 660ms 安静才判断。同一短句必须依次出现一次完整“小迪”和一次动作，二者 token 间隔不得超过 800ms；独立流检测常见否定、引述/问句标记和其他冲突动作，避免最强识别路径掩盖重叠口令。再结合首尾时间与整段发声边界、唯一命中、时长限制拒绝额外讲话和多口令。截断长句、无匹配、不确定、过期结果均不执行；命令后冷却 1200ms 并重新等待安静。

这些是声学保守保护，不能保证理解所有否定、引述、同音字或重叠说话。单独播放的一句完整口令与本人说的声波可能无法区分；不能宣称消除了电视误触发。课程媒体开始播放、打开小迪答疑或小迪录音/朗读抢占仍会暂停本模式。真实家庭噪声、儿童声音、口音、远场/电视和手机效果需要实测。原全文 parser 的文本测试不作为 KWS 语义等价证据。当前小模型在正常语速、唤醒名后停顿的合成样例中仍有漏检；更慢连续说法也未全部通过。因此替换分支仍是实验草稿，不能当作已完成识别验收或发布依据。

## 页序、时效与上下文

语音、按钮、目录、URL 和 `course.focus_lesson_step` 共用 `handleStepChange`，按课件、视频和 3D 展示页序导航，不直接增减模型内部步号。小迪课程上下文只有标题和文本，不含已读图像、视频或连接几何。

采集 epoch 在任何导航（包括 A→B→A）、页数变化、暂停或重新监听时递增，AudioWorklet 丢弃半句，Worker 的旧 epoch 结果不执行；结果到达超过 2 秒丢弃。用户、课程或课时改变、卸载释放整个会话。父导航函数仍同步校验自己的 epoch，覆盖 React 尚未提交的间隙。首尾只提示，不越界。

## 采集与生命周期

`building-voice-capture.ts` 由显式点击创建/恢复 AudioContext，通过原有共享会话互斥；资格通过后才请求麦克风及加载模型。AudioWorklet 做声音分段，通过独立 MessageChannel 直接交给 Worker，3D 主线程不接 PCM、不做推理。浏览器需安全上下文、WebAssembly SIMD、Worker、AudioWorklet；不支持时显示提示并保留按钮，不静默降级到云 ASR 或 ScriptProcessor。

缓冲上限：Worklet 一个 5 秒 Float32 缓冲 + 300ms pre-roll + 20ms 分帧；只允许一个音频段在途，忙时丢弃输入而不排队；Worker 每段创建并销毁识别流，每条检测流最多 9 个匹配观察，不累计特征或 PCM。WASM 初始堆 64MiB、最大 256MiB；异常/退出终止 Worker，释放模型。每段处理后清空音频，不写录音日志或任何音频缓存。

visibilitychange 只检查实际音轨、AudioContext 和采集心跳，不因隐藏无条件暂停；仍工作的屏幕镜像/投屏采集可以继续。轨道 ended/mute、AudioContext 非 running、采集心跳停止、pagehide/freeze 才失败关闭；返回前台、pageshow 或媒体结束均不自动重开。锁屏、后台、镜像与独立投送在各设备的行为不同，无法绕过系统限制，也不保证后台常驻。恢复要求点“继续”，遵守浏览器麦克风授权；不改变系统安全设置、不自动申请屏幕常亮。

模型/WASM 按需从同源版本目录加载，校验字节数和 SHA-256 后存入专用 CacheStorage（仅静态资源）；缓存不可用可在本次会话使用已下载资源。加载失败/超时、推理异常、能力不足均明确提示。无 CDN 回退或外部收费服务。模型版本、重建及许可统一见 [语音协议](../ai/voice-31-upgrade.md#课程端侧固定口令资源)。

## 课程资格端点

`GET /api/tutor/speech/course-control?courseId=…&lessonId=…` 只返回当前用户和 5 分钟资格有效期，`Cache-Control: no-store`。仍调用原 `requireAuth`、`getLessonInCourse`，保留 approved、内容分级、课时归属、有展示页的 building_3d 以及历史未上架直达规则。前端每 4 分钟续查；过期、身份不符、拒绝或网络失败则暂停。刷新资格需要联网，已缓存模型不代表完全脱网无限运行。

该端点不收音频、不识别、不写聊天/代币/识别元数据，也不调用旧识别次数 RPC。每分钟 20 段/UTC 日 120 段的云识别配额不再用于新课程监听。旧 POST 返回 410 提示刷新，不读取请求体或继续上传；普通小迪语音端点、共享预算及权限保持原样。没有数据库迁移或生产数据清理。

## 验收要求

`pnpm exec playwright test -c playwright.building-kws.config.ts` 使用真实课程控件、AudioWorklet、Worker、中文模型和 3D 工作区，只有 Auth/课程数据和麦克风输入是隔离替身，不开物理麦克风。默认严格测试随仓库附带的两组 MeloTTS 合成中文 WAV（正常语速带停顿／0.8 倍语速连续说法，非家庭录音）；可通过 `BUILDING_KWS_TEST_AUDIO_DIR` 指向另一组本地合成 WAV；用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定系统 Chromium。可选持续运行由 `BUILDING_KWS_SOAK_MS` 指定真实经过时间，检查模型实际处理、工作线程堆、3D 交互及释放，并记录漏检；它与严格口令准确性验收分开，不能用加速循环充当半小时稳定性。

覆盖许可/摘要、能力缺失、加载失败、未知/否定/引述/多口令及重叠样本、冷却、暂停/恢复/退出、导航/销毁/音频抢占、页面隐藏与实际中断。音频样本集结果不能证明开放环境准确率；本次结果与资源体积以草稿 PR 的最终验证记录为准，真机 iPhone/安卓/投屏/家庭噪声和长时测试未由自动化代替。


`node node_modules/@playwright/test/cli.js test -c playwright.building-outline.config.ts` 启动隔离本地工作区夹具，使用仓库真实模型与分步打包函数，覆盖桌面/手机视口的翻步、相机保持、静止帧数、减少动态效果、模型切换及卸载。需安装 Chrome；鉴权、零件清单接口由夹具替代，不验证生产课程接入或真机 GPU。截图和结果保存在仓库外的 `../outline-warm-evidence/`。

目录、零件、页序、相机和材质回归与语音回归分开。历史合成声音、替身 Auth/ASR、单隔离 PGlite 的结果不等于真实麦克风、识别准确率、多连接生产预算或实搭通过，也不能重复累加旧测试数。

真实验收仍须记录：手机权限及后台/来电、全屏操作与释放；不同说话者、距离和噪声的准确率/延迟；长声音截断后的恢复；连续陪搭的触屏、误翻、重复翻页和旋转次数；实际上传时长与供应商账单。来源、版本和环境写清楚。

本次不实现持续开放式语音对话或多设备共享监听。端侧固定口令也不提供说话人识别或全句语义保证。当前任务统一见 [下一步](../next-step.md)，不另建一份相互竞争的发布待办。
